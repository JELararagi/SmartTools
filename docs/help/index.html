ツールが画面に出てこない

有効化を確認し、下の製品の「開く場所」でエディター・モード・パネル名を確認してください。環境によってはサイドバーを開いてタブを切り替えます。

図と違う結果になる

試した版、選択対象、モード、フレームを作例と合わせます。まず新規シーンか自分のファイルのコピーで試してください。この版の図解はWindows・Blender 5.1.2を基準にしています。

外部アドオンの操作が使えない

外部アドオン連携を使う場合は、その製品を別途入手し有効にしてください。たとえばSmartRigのAuto-Rig Pro連携に、Auto-Rig Proの利用権は含まれません。
