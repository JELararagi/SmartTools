SmartTools Add-on Manual

Smart Selector Suite Manual

Version 1.0.0 / November 19, 2026 / For Blender 5.1.2

Smart Selector Suite builds your own button screens, called selectors, in a web browser window. With their buttons and sliders you can control Blender bones, objects, collections, shape keys, and custom properties. You are free to choose how buttons are placed, their colors, and their shapes; if you arrange bone buttons in the shape of a body, you get a character picker. The suite also includes layers, which stack motion without breaking the base Action; selection sets, which remember groups of frequently used objects by name so you can select them again; the Collection Manager, which manages collections; GP Select, for Grease Pencil; and Face ARKit, tools for face rigs driven by ARKit expressions. All of them are gathered in one panel named "Smart Selector" in the Sidebar (N panel). Click the "?" help button on each group's header to open a detailed explanation of that group.

1. What This Add-on Does

An add-on that builds your own button screens (selectors) in a browser window, so you can select Blender bones and move shape keys with a single click. It also includes layers that stack motion without breaking the base animation, and selection sets that remember selected objects by name.

  • Save object selections under a name, then recall them later with "Select", "Add", "Subtract", and "Toggle" (selection sets)
  • Create, rename, duplicate, and archive projects, the folders that hold selector files (button screens made in the browser)
  • Create new selectors, open existing ones in the browser to use them (Select mode) or fix them (edit), and mark favorites
  • Send object, collection, and bone selections, shape key values, custom properties, and scripts from the buttons of a selector in the browser to Blender
  • Toggle collection visibility, exclusion, selectability, and more from the Collection Manager popup
  • Use GP Select to select, reorder, and rename Grease Pencil layers, set pass indexes, and use rigging helpers
  • In a file with an ARKit face rig, check expressions, bake them to keys for hand animation, and use animation layers
  • Use Light Display to lighten the screen while you work on animation
  • Set the data storage location, the sync interval, the number of backup generations, and whether scripts may run
When to Use It
  • Save groups such as a character's body, hair, and props as selection sets, and reselect them with a single button every time you work
  • Divide projects by character, create button screens (selectors) inside them, and select or move bones and expressions with clicks
  • In a scene with many collections, switch visibility and exclusion in bulk from the Collection Manager popup
  • Rename Grease Pencil layers all at once, or align their pass indexes
  • With an ARKit face rig, bake captured expressions to keys for hand animation, then stack layers to refine them

4-1. Browser Selectors (Your Own Button Screens)

In a web browser window, you can build your own operation screen (a selector) with buttons, sliders, and text placed freely. Clicking a button selects Blender bones, objects, and collections, and moving a slider changes the values of shape keys and custom properties. If you arrange bone buttons in the shape of a body, you get a picker made just for that character. A selector is a separate window from Blender, so you can place it on a second monitor without narrowing the Blender screen. The selectors you make are saved in the project folder, and you can open one just by clicking its name in the list in the N panel.

How to Use
  1. In "Always-on Toggles" of "Smart Selector" in the N panel, turn on "Browser server" (off by default).
  2. Click + in "Project" and enter a name to create a project.
  3. Click "Create New Selector". A browser window opens in Edit Mode.
  4. Place buttons and sliders, and set what each one does with right-click > "Element Action" > "Action Settings". For a bone button, select bones in Blender's Pose Mode and then click "Capture", and those bones are added together.
  5. Press Ctrl+S to save over the file (add Shift to save under a new name).
  6. Click the name that appears in "Selector Data List" in the N panel to open it in Select mode. Clicking a button moves things in Blender.
Key Points
  • A button can do 10 kinds of things: node selection, one-shot script execution, toggle (ON/OFF) script, timeline control, camera/view control, collection selection, collection visibility toggle, bone selection, mesh selection set, and no function (for decoration or headings).
  • A button whose bones are all selected in Blender lights up. You can see on the selector where your selection currently is.
  • If you click a bone button during Weight Paint, the mode stays the same, and the selected bones and vertex group are switched.

Settings in detail: 5-14. Smart Selector (Summary), 5-15. Project, 5-16. Selector Data List

4-2. Selector Edit Mode (Place Parts and Set What They Do)

In Edit Mode, you place buttons, sliders, and text on the canvas, and set the text, color, shape, size, and action in the fields on the right. Once saved, the same screen can be used as it is in Select mode. Buttons for bones that are selected in Blender light up even while you edit.

How to Use
  1. Add buttons and sliders with "Add, Layout, and Align", and drag them into place on the canvas.
  2. Click a part to select it, and set its text, color, shape, and size in "Element Settings".
  3. Right-click a part, and set what it does with "Element Action" > "Action Settings".
  4. Press Ctrl+S to save over the file. If you make a mistake, undo with Ctrl+Z.
Key Points
  • To move the screen, drag with the middle mouse button, or hold Shift and drag an empty area.
  • When you click "Capture" in the bone field, the bones currently selected in Blender's Pose Mode are added together. You do not need to type bone names.

Settings in detail: 5-16. Selector Data List

4-3. Layers (Stack Motion Without Breaking the Base Animation)

On top of the current animation (the base layer), you can stack touch-up motion as separate layers. For each layer, you can switch on and off, weight (0 to 1), and Additive/Replace to compare, and when you want to keep the result, use "Collapse Animation Layers" to bake it into the keys of the base layer. The target is the selected armature, so this works not only on face rigs but on any rig with an Action.

How to Use
  1. Select an armature that has an Action.
  2. Click "Add Animation Layer", then click the pencil of the new layer to start editing.
  3. Move bones and set keys. The keys go into that layer, and the base does not change.
  4. Click the pencil again to finish editing, and compare the effect with the checkbox, weight, and Additive/Replace.
  5. When you want to keep the result, click "Collapse Animation Layers" to bake it into the keys of the base.
Key Points
  • When you turn off a layer's checkbox, the values that only that layer was driving return to their defaults. To turn a layer off, use this checkbox instead of muting it directly in the NLA Editor.
  • "Collapse Animation Layers" takes time. You can cancel with Esc, in which case nothing is written.

Settings in detail: 5-7. Layers

4-4. Selection Sets (Remember Selected Objects by Name)

Give a name to the group of objects you currently have selected, and reselect it later with a single button. "Select" replaces the selection, and "Add", "Subtract", and "Toggle" combine the set with the current selection.

How to Use
  1. Select the objects you want to remember.
  2. Enter a name in the field at the top of "Selection Set" and click "Create".
  3. When you want to reselect, click the set's row in the list and then click "Select".
Key Points
  • "Add", "Subtract", and "Toggle" add the set's objects to the current selection, remove them from it, or invert them. The contents of the set do not change.
  • To replace the entire contents, use "Update". To add or remove the objects you currently have selected, use + / -.
  • Deleting a set removes only the set, not the objects.

5-3. Face ARKit

Tools for a face rig driven by the 52 ARKit expressions (an armature with the bone cc_arkit_board). In a file that has that rig, this group is open from the start. In a file without the rig, the message "No Face ARKit rig (armature with cc_arkit_board) in this file." appears, and only "Light Display", "External Actions (archive)", and, when an armature is selected, "Layers" are shown.

Location"Smart Selector" panel > "Face ARKit"

ItemWhat it does
Mode: Expression Mode / Mode: Hand-Key ModeThe top row. Expression Mode is the state where the face moves with 52 sliders. Hand-Key Mode is the state after baking, where you set keys directly on the face controllers. The name of the rig appears just below.
Report rowAfter each operation, the result appears below the mode row. A check mark means it passed; red text means it failed or needs checking.
The rig's Text is missingAppears in red when the Text blocks in the rig (ARK_facial_tools.py and ARK_board_layout.json) are not in the file. In that case, do not go on to the next steps.

Important
The buttons that run the rig's Text work only when "Settings" > "Performance / Safety" > "Allow Execute Script" is on. If the file has not allowed automatic Python execution, a confirmation appears when you click, and clicking OK runs that Text for this session only.

The target is the selected armature (or the face rig if none is selected), so this can also be used on body bones.

Save a Frequently Used Group of Objects as a Selection Set

Make it possible to reselect a group such as body, hair, and props with a single button

  1. In Object Mode, select the objects you want to remember (click, Shift+click, box select).
  2. Open "Selection Set" and enter a name (for example, "Hair") in the field at the top.
  3. Click "Create". The set appears in the list.
  4. Later, click the set in the list and then click "Select" to return to the state where only those objects are selected.
  5. To change the contents, select the objects and then click "Update".

Result: The objects in the set are selected in the 3D Viewport and the Outliner.

Create a Project and a Selector

Create and use a button screen (selector) for a character

  1. Open "Always-on Toggles" and turn on "Browser server" (it is off by default).
  2. Open "Project", click the + icon, and enter a name to create a project.
  3. Open "Selector Data List" and click "Create New Selector". An empty selector opens in the browser in Edit Mode.
  4. In the browser, place buttons and sliders, decide what each one moves, and save.
  5. The file appears in the list (if it does not, click the refresh icon). Click the selector name button to open it in Select mode.

Result: When you click a button in the browser, the target in Blender is immediately selected or changed.

Switch Collection Visibility in Bulk

Switch the visibility and exclusion of collections in the Collection Manager popup

  1. Switch to Object Mode.
  2. Open "Collection Manager" and click "Open Collection Manager". The first time, the tool is loaded and then opened.
  3. In the popup, click the icons in each collection's row to switch visibility and exclusion.

Result: The same changes appear in the Outliner.

Lighten the Browser Sync in a Heavy Scene

Reduce the load when Blender is slow while a selector is open

  1. Open "Settings", then open "Performance / Safety".
  2. Raise "State Sync Interval (s)" (for example, 0.8 to 1.0).

Result: The state is sent to the browser less often, and Blender becomes lighter.

8. Troubleshooting

The browser does not open when I click a selector button.
Check that "Browser server" in "Always-on Toggles" is turned on. It is off by default, and when it is off, new selector screens do not open.
I saved a selector, but it does not appear in the list.
Click the refresh icon in "Selector Data List" ("Refresh Selector Data List"). Also check that the current project is the same as the one you saved to.
If I delete a selection set, are the objects deleted too?
No. "Delete Selection Set" deletes only the set. The objects remain in the scene as they are.
Can I use a selection set in another file?
No. Sets are saved inside the .blend of that scene.
Archived projects do not appear in the list.
Turn on "Settings" > "Project List Section" > "Show Archived Projects". Archiving only moves the folder to __ARCHIVE__; it does not delete it.
The script buttons in a selector do not work.
Check that "Settings" > "Performance / Safety" > "Allow Execute Script" is on. For selectors you did not make yourself, it is safer to keep it off.
"Face ARKit" shows "No Face ARKit rig (armature with cc_arkit_board) in this file."
It means this file has no ARKit face rig (armature with cc_arkit_board). In that case, only "Light Display", "External Actions (archive)", and, when an armature is selected, "Layers" can be used.
Is it safe to save with "Light Display" left on?
A normal save turns it off just before writing and restores it after saving. However, autosave and recovery files are written with it still on. When you open such a file, turn it off once and check.

For problems common to every add-on, such as an add-on not appearing or the interface language not changing, see "Troubleshooting" in the SmartTools Overall Specification.

9. Glossary

N Panel (Sidebar)
The vertical area that appears at the right side of an editor. Open and close it with the N key.
Selection Set
A saved object selection that has been given a name.
Selector
An operation screen shown in a web browser, with buttons, sliders, and images arranged on it. It is saved as a file (JSON).
Project
A folder that holds selector files and images.
Select Mode / Edit Mode (Selector)
Select mode is the mode for using a selector, and Edit Mode is the mode for fixing the layout and what the buttons do.
JSON
Text data in which values are arranged in a fixed format. It is used in selector files and in the Bridge fields.
Bridge
The mechanism that connects browser selectors and Blender.
Handler
A process that runs automatically, for example when a file is opened.
QCD
A mechanism that assigns collections to numbered slots so you can switch between them quickly with the number keys and similar.
Grease Pencil
A Blender object for drawing 2D art inside 3D.
Pass Index
A number assigned to layers and materials. It is used to tell them apart in compositing and similar work.
Action
Blender's animation data that groups keys (animation values) together.
NLA
A Blender mechanism for stacking and arranging multiple Actions.
Bake
Writing the result of motion as keys on every frame.
Subdivision (Modifier)
A feature that divides a mesh into finer pieces to make it look smooth. It can make things heavy.
