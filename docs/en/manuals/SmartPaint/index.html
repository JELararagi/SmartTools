About this tool

SmartPaint Suite adds a paint-software-style layer system to Blender's built-in Texture Paint (the feature that paints color directly onto 3D objects or images). When you open a PSD/PSB file (a Photoshop image format), the layer structure is loaded as is. Select the layer you want to paint on, paint with Blender's brushes, and save with the original structure intact. Ordinary images such as PNG open as a single paint layer. Even without an image, click "Switch to Paint Material" to start painting right away on a blank layer. The suite also provides adjustment layers (layers that change color tone), masks, selections, fill and gradient, transform, brush assets and color palettes, preparation before painting (face mask and UV checker), image processing, and integration with Photoshop and Clip Studio Paint. For how to install, localize, open the N panel, and use the "?" help button, see the relevant chapters of the SmartTools Overall Specification.

1. What This Add-on Does

A paint add-on that lets you paint and save layered images, such as PSD files, layer by layer inside Blender.

  • Without opening an image, set up a material for painting and a blank layer with one click, and start painting right away.
  • Open a PSD/PSB file and paint with Blender's brushes on only the layer you selected, keeping the layer structure.
  • Open an ordinary image such as PNG as a single paint layer and paint on it.
  • Add, delete, move up and down, group, and show or hide paint layers and adjustment layers.
  • In the 3D Viewport, paint on the selected layer while viewing all layers stacked together (live compositing).
  • Set opacity, blend mode, clipping, and mask for each layer.
  • With adjustment layers, apply Brightness / Contrast, Levels, Hue / Saturation / Lightness, Color Balance, Invert, Posterize, Threshold, and Gradient Map without changing the original artwork.
  • In the Image Editor, create rectangle, ellipse, lasso, and polygon selections, and paint or fill only inside them.
  • Fill, gradient, erase, copy and paste, move, scale, rotate, and flip.
  • Choose Blender brush assets and load GIMP GBR brushes.
  • Create color palettes, load them from GPL files or images, or generate them from harmonious colors (such as complementary colors).
  • Expand a face mask by UV island or mesh island, and save it with a name and load it later (3D Viewport).
  • Split and combine RGBA, flip and rotate, edge padding, tile border blending, normal map conversion, and SDF generation, all created as new images (Image Editor).
  • Exchange images with Photoshop or Clip Studio Paint.
When to Use It
  • Prepare a bare 3D object for painting with one click and lay down base colors.
  • Load a character's PSD texture into Blender and add paint to only some layers while viewing the 3D object.
  • Change only the skin tone with an adjustment layer and compare, keeping the original artwork.
  • Apply a face mask to only the clothing UV island and paint without going outside it.
  • Convert the direction of a normal map between OpenGL and DirectX.
  • Open an image you are painting in Photoshop or Clip Studio Paint and touch it up.

2. Key Features

This chapter walks through the features unique to this add-on, using numbered callouts on each figure. The numbers in a figure match the numbered list below it. Click a figure to enlarge it. Each individual setting is described under its own heading in Chapter 5.

2-1. Paint and Save as PSD Layers (Document and Layers)Top Selling Point

You can paint with stacked layers inside Blender. PSD/PSB files open with their layer structure kept, and after painting they can be saved to PSD as layers (adjustment layers are included). When painting, it switches to a material for painting without changing the nodes of the original material, and you can restore it when you finish. With "Live", you can paint on one selected layer while viewing all layers stacked in the 3D Viewport.

How to Use
  1. Select the object you want to paint on, and click "Switch to Paint Material" in "Document" in the "Smart Paint" tab (after clicking, it changes to ①). If you have a PSD, open it with the folder icon ②.
  2. Add a layer with the + at ⑦, choose the painting target in the list at ⑥, and paint with a brush.
  3. Paint while checking the appearance of all stacked layers with "Live" at ③.
  4. With the overlapping squares icon ("Save As Image") at ②, save with a name ending in .psd. From then on, you can overwrite with the floppy disk icon.
Good to Know
  • "Switch to Paint Material" cannot be used on an object without a UV map.
  • "Save Image" cannot be clicked if there is no original file. If you save as a PSD/PSB with a different name, that PSD becomes the original file. If you save as PNG or similar with a different name, it only writes out a copy of the stacked result.
  • A document with no original file (one created by switching) stays inside the .blend when you save it.
  • After moving to another object, reselect a layer in the list before painting with a brush.

Settings in detail: 5-2. Document, 5-3. Layers

2-2. Change Color Tone Without Changing the Original Artwork (Adjustment Layers)See the Figures

An adjustment layer holds no artwork and only changes how the layers below look. There are eight types, such as Hue / Saturation / Lightness, and the values can be changed any number of times later. Hiding it brings back the original colors, so you can try color tones without repainting. When you save to PSD, the adjustment layers are included too, and even after reopening, you can continue working with the saved values.

How to Use
  1. Select the layer of the artwork whose color you want to change in the list.
  2. Click the color icon ("Add Adjustment Layer") at ④, choose "Hue / Saturation / Lightness" or another option in "Type", and click OK.
  3. Open "Properties" and move the values at ⑦.
  4. Click "Live" at ② to check the appearance. After changing values, click it again.
  5. If you save as PSD with a different name, the adjustment layer is included too.
Good to Know
  • An adjustment layer holds no artwork, so you cannot paint on it with a brush (a lock icon appears in the list).
  • There are eight types: Brightness / Contrast, Levels, Hue / Saturation / Lightness, Color Balance, Invert, Posterize, Threshold, and Gradient Map.
  • An adjustment layer can be deleted with "Remove Layer" (-) even when there is only one paint layer.
  • If you save as PNG or similar with a different name, it only writes out a copy of the stacked result. To keep adjustment layers, save as PSD/PSB.

Settings in detail: 5-7. Properties, 5-3. Layers

2-3. Paint Only Inside a Selected Area (Selection and Draw)See the Figures

Select part of the image so that brushes, fill, erase, gradient, and transform take effect only inside it. To create the area, choose a rectangle, ellipse, lasso, or polygon shape in the Image Editor and drag over the image. You can combine it with the current area using "Add", "Remove", and "Intersect", so you can make several separate spots into one area and paint them together. On a 3D object, only the faces whose UV overlaps the area receive color.

How to Use
  1. In the "Smart Paint" tab of the Image Editor's Sidebar, open "Selection".
  2. Choose a shape at ⑥ and drag over the image to create an area.
  3. To paint a separate spot too, choose "Add" at ⑤ and drag again.
  4. In "Draw", choose a color at ⑩ and click "Fill" at ⑨.
  5. When done, click "Deselect" (X) at the right end of ⑦ to return to the whole layer.
Good to Know
  • The selection is not saved in the PSD.
  • It is separate from Blender's built-in selection. Start the operations that create an area from the "Smart Paint" tab of the Image Editor.
  • "Transform" (move, scale, rotate, flip) also affects only the artwork inside the area, if there is one.
  • For "Poly", click to add points, and confirm with Enter, Space, a double-click, or a click on the first point. Esc cancels.

Settings in detail: 5-4. Selection, 5-5. Draw, 5-6. Transform

4. Where to Find It

It is in the "Smart Paint" tab of the N panel (Sidebar) in the 3D Viewport and the Image Editor (including the UV Editor). When you open the tab, a "Smart Paint" heading appears at the top, with a section header for each feature below it. The same tab also appears in other editors, such as the Node Editor. However, inside "Layers", "Selection", "Draw", "Transform", and "Properties", it shows "Available in the 3D Viewport, Image Editor, and UV Editor" and cannot be used.

  1. For how to open the N panel, see the relevant chapter of the SmartTools Overall Specification.
  2. In the 3D Viewport, select one mesh (an object with a shape).

5. Features

Each heading is explained in order from the top of the panel. Click the "?" to the right of a heading to show the same explanation in Blender. The blue "Example" boxes show real operations on simple models such as Suzanne, with the 3D Viewport before and after.

5-1. Always-on Toggles

Manage processes that run at times other than when you click a button, using on / off switches. When opened, four switches are listed. If you turn all of them off, no processes keep running repeatedly in the background while you are idle. It is closed at first.

LocationThe topmost section header of the Smart Paint tab

ItemWhat it does
N-panel State SaveWhile on, the state of the N panel, such as which section headers are open or closed, is saved to the SmartPaint Suite settings file. When off, it is not saved until you turn it on again. It is on at first.
Animated BrushWhen on, it watches your painting operations and advances the brush texture of an image sequence. It is off at first.

6. Common Tasks

Switch, Paint Right Away, and Save as PSD

You can start painting without preparing an image, and keep what you painted in a file.

  1. In the 3D Viewport, select a mesh that has a UV map.
  2. Click "Switch to Paint Material" in "Document". A blank layer is prepared and Texture Paint mode is entered.
  3. Paint with a brush, or fill with "Fill" in "Draw".
  4. Click the overlapping squares icon ("Save As Image") and save with a name ending in .psd.
  5. After painting more, overwrite-save with the floppy disk icon ("Save Image").

Result: The PSD becomes the original file of this document. Even without writing it to a file, the artwork stays inside the .blend when you save it.

Open a PSD, Paint on Layers, and Save

Add paint to some layers while keeping the PSD's layer structure.

  1. In the 3D Viewport, select the mesh you want to paint on.
  2. If no material is assigned, or if you want to keep the original material, click "Switch to Paint Material" in "Document".
  3. Click the folder icon ("Open Image") in "Document" and choose the PSD. The blank layer prepared when you switched is replaced by the PSD's layers.
  4. In the "Layers" list, click the row of the layer you want to paint on.
  5. Enter Blender's built-in Texture Paint mode and paint with a brush.
  6. To paint while viewing the overall appearance, click "Live".
  7. Save with the floppy disk icon ("Save Image").

Result: The layer you painted on changes, and the PSD's layer structure is saved as is.

Change Only the Color Tone with an Adjustment Layer

Try color tones without changing the original artwork.

  1. In the "Layers" list, select the layer whose color tone you want to change. The new adjustment layer is inserted above it.
  2. Click the color icon ("Add Adjustment Layer"), choose "Hue / Saturation / Lightness" or another option in "Type", and click OK.
  3. Open "Properties" and move values such as "Hue", "Saturation", and "Lightness". Check the overall appearance with "Confirm", or click "Live" to check it.
  4. To discard it, hide the adjustment layer with the eye icon in the list, or select the adjustment layer and delete it with "-" ("Remove Layer").
  5. To keep it in a file, save as a PSD with "Save As Image". The adjustment layer and its values are also stored in the PSD, and after changing values you can overwrite with "Save Image".

Result: Only the appearance of the layers below changes, and the original artwork remains.

Fill Only Inside a Selection

  1. Open the Image Editor and use the "Smart Paint" tab of its N panel.
  2. Open "Selection" and choose "Replace".
  3. Click the rectangle icon and drag over the image to create a selection.
  4. Open "Draw", set the color and "A", and click the color icon ("Fill").
  5. When done, click "X" ("Deselect").

Result: Only the inside of the selection is painted. If you make a mistake, undo it with "Undo Edit".

Paint Only on a Clothing UV Island

Paint only some faces, without going outside them.

  1. In Texture Paint mode in the 3D Viewport, use Blender's built-in face mask and select one face in the area you want to paint.
  2. Open "Paint Preparation" and click "Expand to UV Island".
  3. To reuse it later, give it a name and save it with "Save Mask".
  4. When you finish painting, remove it with "Clear Face Mask".

Result: The brush takes effect only on the faces of that UV island.

Convert a Normal Map Between OpenGL and DirectX

  1. In the Image Editor, display the normal map you want to convert (a Non-Color image).
  2. Open "Image Utilities" and click "Convert Map...".
  3. Choose "Normal OpenGL ↔ DirectX" and click OK.

Result: A new image with the green channel inverted is created. The original image does not change.

7. Troubleshooting

"Available in the 3D Viewport, Image Editor, and UV Editor" is shown and I cannot use it.
"Layers", "Selection", "Draw", "Transform", and "Properties" can be used only in the N panel of the 3D Viewport, Image Editor, and UV Editor. In other editors, this message is shown and the contents cannot be used.
"Select a mesh material" or "Select a mesh object" is shown.
Select a mesh in the 3D Viewport. If there is no material, click "Switch to Paint Material".
I can no longer paint after switching to "Confirm".
"Confirm" is a view-only display for checking the whole. When you want to paint, switch back to "Individual" or "Live".
"Erase result is finalized in Confirm mode" was shown.
It appears when you erase an opaque area in the "Live" display. Click "Confirm" and check it in the overall appearance.
"No UV Map" is shown.
That object has no UV map. Create a UV first. Without a UV map, "Switch to Paint Material" cannot be used either.
Clicking the selection or gradient button does not start anything.
These operations are performed by dragging over the image, so click them from the Smart Paint tab of the Image Editor. They cannot be started from the 3D Viewport.
Is the original material overwritten?
"Switch to Paint Material" switches while keeping the original material saved. You can restore it with "Restore Original Material".
I cannot click "Paint Preparation" or "Image Utilities".
"Paint Preparation" can be used only in the 3D Viewport, and "Image Utilities" only in the Image Editor and the UV Editor. In other editors, "Available in the 3D Viewport" or "Available in the Image and UV Editors" is shown.
Does merely opening "External Paint" start the integration in the background?
No. It starts only when you click "Connect".
Does "Undo Edit" also undo strokes painted with a brush?
This button undoes SmartPaint Suite edits such as fills and transforms.
When I click "Live", "Live compositing is unavailable" is shown.
Fix the layers or the file as the message explains, or view the whole with "Confirm".
Where is the artwork I painted after switching saved?
While there is no original file, it stays inside the .blend when you save it. To make it a file, write it out as a PSD or PNG with "Save As Image". A PSD can be overwrite-saved to continue, but PNG and other formats only write out a copy and do not become the document's original file.
After moving to another object and coming back, the brush target is wrong.
After moving to another object, reselect a layer in the "Layers" list before painting with a brush.
Applying "Edge Padding..." does not change the appearance.
It spreads only the color in the transparent areas and does not change the transparency. If you use the new image as a texture, gaps at seams become less noticeable.
Clicking "-" shows "The last paint layer cannot be deleted."
It appears when only one paint layer remains in the document and you have that layer selected. At least one paint layer is required. An adjustment layer can be deleted even when there is only one paint layer.
After switching to "Live", the object turned completely white in the 3D Viewport.
When there are only transparent layers with nothing painted yet, it appears white. After you paint or click "Fill", it appears in that color.

For problems common to every add-on, such as an add-on not appearing or the interface language not changing, see "Troubleshooting" in the SmartTools Overall Specification.

8. Glossary

Texture Paint
A Blender built-in feature for painting color directly onto 3D objects or images with a brush.
PSD/PSB
Photoshop image formats. They can hold layer information. PSB is for large images.
Layer
A mechanism that divides artwork into levels, like stacking transparent sheets.
Adjustment Layer
A layer that holds no artwork and only changes the color tone of the layers below.
Mask
A black-and-white image that determines which parts of a layer are shown and which are hidden.
Clipping
Showing the upper layer only where the layer directly below has paint.
Blend Mode
The rule for how a layer is stacked on those below it (such as Multiply and Screen).
Live Compositing
A display method in which you paint on the selected layer while the 3D Viewport shows all layers stacked.
UV / UV Island
A UV is a table that maps 3D faces to positions on an image. A UV island is a group of faces connected in the UV.
Face Mask
A Blender feature that makes the brush take effect only on the selected faces.
Texel Density
How many pixels of the image are used per meter of a 3D object.
Edge Padding
A process that spreads color into the transparent areas outside the artwork so that gaps do not show at seams.
SDF
An image that represents the distance from each pixel to the boundary as brightness.
Normal Map (OpenGL/DirectX)
An image that represents surface bumps with color. The direction of green is reversed between the two conventions.
Non-Color
An image setting that treats the image as data rather than color. It is used for normal maps and the like.
GBR/GPL
GBR is the file format for GIMP brushes, and GPL is the file format for GIMP palettes.
Brush Assets
Blender brushes that can be saved and reused in other files.

Limitations and Notes

  • "Layers", "Selection", "Draw", "Transform", and "Properties" can be used only in the 3D Viewport, Image Editor, and UV Editor.
  • Creating a selection and the gradient are done by dragging over the image in the Image Editor.
  • "Paint Preparation" can be used only in the 3D Viewport, and "Image Utilities" only in the Image Editor and the UV Editor.
  • "Switch to Paint Material" can be used only on a mesh that has a UV map.
  • The "Confirm" display is view-only and you cannot paint.
  • The selection is not saved in the PSD.
  • "Undo Edit / Redo Edit" handles SmartPaint Suite edits (fill, erase, gradient, transform, paste, and so on).
  • Every "Image Utilities" function creates a new image. The original image does not change.
  • The input of "Convert Map..." must be a Non-Color image.
  • Eight types can be added as adjustment layers: Brightness / Contrast, Levels, Hue / Saturation / Lightness, Color Balance, Invert, Posterize, Threshold, and Gradient Map. If a PSD contains any other adjustment, "Keep Photoshop/CSP native record" is shown and no value fields appear.
  • "Connect" in "External Paint" can be used when the file of the image opened in SmartPaint Suite exists on disk. The other app (Photoshop or Clip Studio Paint) is also required. In addition, psd-tools and Pillow must be installed in Blender's Python (they are not included with Blender). If you click "Connect" when they are not installed, "External bridge requires psd-tools and Pillow in Blender Python." is shown and the integration does not start.
  • After moving to another object, reselect a layer in the "Layers" list before painting with a brush.
  • Image processing such as "Generate SDF..." takes time on a large image when a value is set to its maximum (about 20 seconds for a 4096 px image with the width at its maximum).
  • When only one paint layer remains in the document, that paint layer cannot be deleted (an adjustment layer can be deleted).
  • A mask can be created for paint layers and groups. It cannot be created for an adjustment layer.
