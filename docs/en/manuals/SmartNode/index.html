About this tool

SmartNode Suite is an add-on that makes work in the node editor (the screen where you connect nodes to build materials and image composites) easier. With one button you can select nodes and insert a merge node between them, rebuild links (the lines that connect nodes), change labels (the names shown above nodes) in bulk, arrange cluttered nodes automatically, select by following connections, and delete unused nodes. It also adjusts the look of the node editor (grid and background colors), builds image textures, colors nodes, loads node groups from external files, and adds extra noise nodes. The buttons are in the "Smart Node" tab of the Sidebar, divided into section headers by purpose.

1. What This Add-on Does

A node tool that rearranges cluttered nodes into a readable layout with one button, and also merges and wires selected nodes, selects and frames nodes by following their connections, all from Sidebar buttons.

  • Insert Mix, Math, Shader, Geometry, Alpha Over, and Depth Combine merge nodes between the selected nodes.
  • Add a full set of nodes for an image texture (Texture Coordinates, Mapping, and Image Texture).
  • Select images whose names contain base color, roughness, normal, and so on, and the texture nodes that connect to the Principled BSDF are built automatically.
  • Detach output links, swap links, add reroutes, connect the active node to the selected nodes, and connect to an output node.
  • Clear, batch change, and copy labels, batch change Mix and Math types, and adjust the Mix factor.
  • Automatically arrange a whole node tree or selected branches in order of connection. You can also align edges, distribute evenly, and snap to the grid.
  • Select nodes by conditions such as upstream, downstream, same type, and unconnected.
  • Color nodes, enclose them in frames, delete unused nodes, and reload images.
  • Apply the node editor's grid color, background color, wire colors, and more to the Blender theme.
When to Use It
  • The nodes in a material are so cluttered that they are unreadable, and you want to rearrange them all at once.
  • You load many texture images and want to save the effort of connecting them to the Principled BSDF.
  • You want to connect two colors or shaders with a Mix node by selecting them and pressing one button.
  • In a large node tree, you want to select only the nodes that lead to a certain output.
  • At the end of your work, you want to clean up unused nodes and empty frames.

2. Key Features

This chapter walks through the features unique to this add-on, using numbered callouts on each figure. The numbers in a figure match the numbered list below it. Click a figure to enlarge it. Each individual setting is described under its own heading in Chapter 5.

2-1. Rearrange Cluttered Nodes with One Button (Arrange All Trees)Top Feature

When nodes are scattered everywhere and lines cross, you cannot tell what is connected to what. Click "Arrange All Trees" in "Layout / Arrange" and all the node trees in the file are rearranged from left to right in order of connection. The connections do not change. The spacing and the way crossing lines are reduced are set in the "Align Nodes" fields just above. There are also "Arrange Selected Nodes", which arranges only the selected nodes, and buttons that arrange by level of connection, in a single row, in a grid, and more.

How to Use
  1. Open a node tree in a node editor (such as the Shader Editor) and look at the Sidebar "Smart Node" tab > "Layout / Arrange" (open from the start).
  2. If needed, change ⑦ "Spacing" and ⑧ "Crossing Reduction Iterations".
  3. Click ⑤ "Arrange All Trees". To arrange only the selected nodes, use ⑥ "Arrange Selected Nodes".
  4. To return to the original arrangement, use Undo (Ctrl+Z).
Good to Know
  • "Arrange All Trees" arranges all the node trees in the file, not just the open tree. To arrange only the open tree, use "Lay Out All".
  • "Smart Hierarchy Layout" and "Quick Align" target all nodes when nothing is selected.
  • "Recenter Selected" and "Recenter All Trees" move the nodes together so that the point chosen with "Recenter Origin" (such as "Center") lands on the origin (0, 0).

Settings in detail: 5-9. Layout / Arrange

2-2. Connect Selected Nodes Without Drawing Lines (Merge Selected Nodes and Connect to Output)See It in Figures

Drawing a line from a tiny socket every time you connect nodes takes effort. With SmartNode Suite, you just select nodes and click a button to connect them. "Merge Selected Nodes" inserts a merge node, such as Mix or Math, between two or more selected nodes. "Connect to Output" reconnects the output of the selected node (the active node) to an output node such as Material Output, so you can check the result of a node you are still building right away in the 3D Viewport.

How to Use
  1. Select the nodes. For "Merge Selected Nodes", select two or more (① and ②). For "Connect to Output", select the node whose result you want to see (⑤).
  2. In the Sidebar "Smart Node" tab, open "Merge / Composite Nodes" or "Links / Reroutes".
  3. For "Merge Selected Nodes", choose how to merge from the menu. For "Connect to Output", just click.
Good to Know
  • The contents of the "Merge Selected Nodes" menu change by node tree type. In geometry node trees, you connect with "Join Geometry", "Intersect", "Union", and "Difference".
  • Where the inserted node is placed and whether it is collapsed are set with "Mix Node Position" and "Hide Mix Nodes" in the add-on settings.
  • "Connect to Output" cannot be used in geometry node trees.

Settings in detail: 5-5. Merge / Composite Nodes, 5-7. Links / Reroutes

2-3. Put Everything Connected into One Frame (Frame Connected)Follow the Connections

In a large node tree, it is hard to see by eye where one material's group begins and ends. The buttons in "Selection / Branches" follow links from the selected nodes. With just one node selected, "Frame Connected" follows every node connected by lines and puts them all in a single frame (box). This is handy when you want to move the group as a whole. To only select without making a frame, use "Upstream", "Downstream", and "Connected".

How to Use
  1. Select one node in the connections you want to group (①).
  2. In the Sidebar "Smart Node" tab > "Selection / Branches", click ② "Frame Connected".
Good to Know
  • An existing frame that contains only the nodes being enclosed is placed inside the new frame as it is.
  • "Create Backdrop Frame" encloses only the selected nodes in a frame.

Settings in detail: 5-10. Selection / Branches

4. Where to Find It

It is in the "Smart Node" tab of the node editor Sidebar (N panel). The same panel can also be shown in the Sidebar of other editors, such as the 3D Viewport and the Image Editor. Which editors show it follows the settings in Smart Tools Manager. The buttons that operate on nodes can be pressed only while a node tree that can be edited in the node editor is open.

Changes the colors of the node editor's grid, background, and wires (the lines of links). The values are written to the Blender theme (the screen color scheme) currently in use.

LocationThe section header below "Overview"

5-5. Merge / Composite Nodes

Inserts a merge node between the selected nodes. Select two or more nodes before using it.

LocationThe section header below "Node Editor View"

ItemWhat it does
"Merge Selected Nodes"Click it to open a menu where you choose how to merge. The contents change depending on the node tree type.

Rebuilds links without deleting nodes.

"Snap Nodes to Grid", "Swap Positions"Fits the positions of the selected nodes to the grid. "Swap Positions" swaps the locations of two selected nodes.

6. Common Tasks

Rearrange Cluttered Material Nodes

Make the whole node tree easy to read

  1. Display the material nodes in the Shader Editor.
  2. Open the "Smart Node" tab in the Sidebar.
  3. Click "Lay Out All" in "Layout / Arrange".
  4. If you do not like the result, press Ctrl+Z to undo.

Result: The nodes are arranged level by level of connection.

Build Principled BSDF Nodes from Texture Images

Connect many texture images to the Principled BSDF without connecting them by hand

  1. In the Shader Editor, select the Principled BSDF node.
  2. Open "Texture Setup" and click "Add Principled Texture Setup".
  3. In the file browser, select the images whose names include base color, roughness, normal, and so on, all together, and confirm.

Result: Image nodes are added and connected to the inputs of the Principled BSDF.

Connect Two Nodes with a Mix

Combine the outputs of two colors in a single Mix node

  1. Select the two nodes you want to combine.
  2. Open "Merge / Composite Nodes" and click "Merge Selected Nodes".
  3. Choose "Use Mix Nodes", then choose a blend method.

Result: A Mix node is inserted between the two nodes, and both are connected to it.

Clean Up Nodes at the End of Your Work

Delete unused nodes to lighten the tree

  1. Look over the nodes and check which ones have no line leading to an output node such as Material Output. "Unconnected" selects only nodes that have no lines at all, so branches connected by lines are not selected.
  2. Make sure there are no nodes you want to keep. Muted nodes are also deleted.
  3. Click "Delete Unused Nodes" in "Node Management" and confirm in the dialog that appears.

Result: Nodes that do not reach an output are deleted, along with any branches connected by lines. Muted nodes and empty frames are also deleted.

7. Troubleshooting

A button is gray and cannot be clicked.
The buttons that operate on nodes can be used only while a node tree that can be edited in the node editor is open. Some buttons are also limited to a certain node tree type, such as "Add Texture Setup" for shaders and "Save Viewer Image" for the Compositor.
Nothing happens when I press the keys in the hotkey list or Shift+W.
This add-on does not change key assignments automatically. In the Keymap section of Preferences, assign a key to the command you want to use.
I changed the colors in "Node Editor View", and the colors changed in other files too.
This is because the values in this section header are written to the Blender theme. To return to the default colors, click "Reset".
The node preset list does not appear.
After setting a folder with "Choose Folder", click "Refresh". Only the first 64 items appear in the Sidebar. You can use all of them from "Template Menu".
"Run One-shot Sync" cannot be used.
First enable "Noise Node Compatibility" in "Always-on Toggles".
Nodes containing the text I searched for with "Select by Text" are not selected.
Check "Target". Use "Name / Label" to search by node header names, "Sockets" to search by input or output names, and "All Text Fields" to search broadly. "Node Type" searches only internal English names (such as math), so it finds nothing with Japanese text.

For problems common to every add-on, such as an add-on not appearing or the interface language not changing, see "Troubleshooting" in the SmartTools Overall Specification.

8. Glossary

Node
A box that represents one process. Nodes are connected with lines to build materials and image composites.
Node Tree
A connected group of nodes. There are types such as shader (materials), Compositor (image compositing), and geometry nodes (shape processing).
Socket
The round plug-in points on the left and right of a node. The left ones are inputs and the right ones are outputs.
Link
A line that connects sockets to each other.
Reroute
A small relay point placed partway along a link. It is used to tidy the path of a line.
Frame
A box that encloses several nodes. It makes a group easier to recognize.
Active Node
The last one selected among the selected nodes. It is displayed with a bright outline.
Upstream and Downstream
Seen from a given node, the nodes connected on its input side are upstream, and the nodes connected on its output side are downstream.
Mute
Temporarily disabling a node without deleting it.
Principled BSDF
The standard shader node that sets color, roughness, metallic, and more together.
Theme
The color scheme settings of the Blender screen.
Origin (0, 0)
The center of the node editor's coordinates.

Limitations and Notes

  • The buttons that operate on nodes can be used only while a node tree that can be edited in the node editor is open. In other editors they are displayed but cannot be clicked.
  • "Add Texture Setup", "Add Principled Texture Setup", and "Select Objects Using Material" are for shader node trees only.
  • "Multiple Images" and "Image Sequence" can be used only in shader and compositor node trees.
  • "Reset Backdrop" and "Save Viewer Image" are for the Compositor only.
  • "Connect to Output" and "Reload Images" cannot be used in geometry node trees.
  • Noise nodes can be added only to shader and geometry node trees.
  • Only the first 64 node presets are shown in the Sidebar.
  • This add-on does not change key assignments automatically. Assign the keys in the hotkey list yourself in the Keymap section of Preferences.
  • The values in "Node Editor View" are written to the Blender theme and also affect other files.
  • The behaviors of "Move Linked Branch" (160 to the right), "Stack Nodes" (a single vertical column from top to bottom), and "Distribute Node Grid" (the number of columns is automatic) are fixed, and there are no fields to change the distance or direction.
  • "Prefix" and similar fields in "Rename Selected Nodes" add text to the internal name (in English) of nodes that have no label. They do not add to the name displayed on a node in Japanese. To add text in Japanese, use "New Name".
  • In "Rename Selected Nodes", when a name would match that of an unselected node, or when multiple nodes would get the same name without numbering, a suffix such as .001 is added to the end of the internal name. This is because Blender cannot have duplicate internal names. The label displayed on the node stays exactly as the text you specified.
