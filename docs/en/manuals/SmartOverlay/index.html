SmartOverlay Suite Manual

Version 1.0.0 / November 19, 2026 / For Blender 5.1.2

About this tool

SmartOverlay Suite is an add-on that adds overlays, drawn on top of the Blender screen. It can display the vertices, edges, and faces you are editing in any color and size. You can also change how parts hidden behind objects are shown. It also includes the following tools: a check for modeling problems (Topo Check); a display that shows the influence range of proportional editing by color intensity; "Smart Measure," which measures and displays dimensions; the "Image Dimensions Viewer," which shows image sizes; and "Silhouette Mode," which lets you check a shape as a black silhouette. All operations are done in the "Smart Overlay" tab of the Sidebar.

1. What This Add-on Does

An add-on that overlays easy-to-read colors for vertices, edges, and faces, display of hidden back sides, topology checks, the range of proportional editing, measurements, and more on the 3D Viewport.

  • Display the vertices, edges, and faces in Edit Mode in different colors for visible parts, hidden parts, selected parts, and parts under the mouse (hover)
  • Display hidden vertices, edges, and faces, choosing from "X-Ray Only," "Always," or "None"
  • In Object Mode and Sculpt Mode, highlight the vertices, edges, and faces of the object under the mouse
  • In the UV Editor, highlight the UV vertex, edge, or face under the mouse, and also show by color the UVs that share a vertex or edge of the same mesh
  • In solid display, draw an outline with a color and thickness you choose, in place of the standard Blender outline (High-Precision Outline)
  • Display the influence range of proportional editing as a heatmap (a map of color intensity) in the 3D Viewport and UV Editor
  • Mark seam, sharp, non-manifold, crease, and bevel weight edges, as well as N-gons, small faces, and back faces, by color (Topo Check)
  • Display the grid spacing dimensions in the 3D Viewport, and place measurements such as distance, angle, arc, and area (Smart Measure)
  • Display the image resolution on Image Texture nodes in the Node Editor and in the Image Editor (Image Dimensions Viewer)
  • Switch the 3D Viewport to a black silhouette on a white background to check the outline of a shape (Silhouette Mode)
  • For heavy scenes, reduce the display load with an optimization preset
  • Save and recall display settings as presets, and keep separate settings for the scene in each .blend file
When to Use It
  • When you want to see the selected vertices and edges thick and in clear colors while modeling
  • When you want to check vertices on the back side of an object without turning on X-Ray
  • When you want to find modeling problems such as N-gons and non-manifold edges all at once
  • When you want to see by color how far proportional editing will move things, before you move anything
  • When you want to display the dimensions of a character or a small prop in the viewport and check them
  • When you want to check the resolution of a texture image without opening the node
  • When you want to look at only the silhouette of a pose or shape to check how readable it is

2. Key Features

This chapter walks through the features unique to this add-on, using numbered callouts on each figure. The numbers in a figure match the numbered list below it. Click a figure to enlarge it. Each individual setting is described under its own heading in Chapter 5.

2-1. Tell Apart the Mesh You Are Editing by Color (Mesh and Curve Display)Top Feature

Draws clear colors over the vertices, edges, and faces in Edit Mode. In place of Blender's standard black lines, thick white edges, a blue face fill, and dots at face centers are overlaid, and selected faces are filled in deep orange, so you can see at a glance what you have selected. Back edges hidden behind front faces can also be seen through in a color or dashed line you choose, without turning on X-Ray. The color, size, and the modes in which they appear can be set separately for vertices, edges, and faces. For curves it also shows control points and shape lines, and for lattices it shows control points and cage edges.

How to Use
  1. Select a mesh and enter Edit Mode.
  2. In "Always-on Toggles" in the "Smart Overlay" tab of the Sidebar, set "Mesh and Curve Display" to "On" (the same as "Enable" at ⑪).
  3. In "Vertex Settings," "Edge Settings," and "Face Settings," set the colors and sizes (⑥ to ⑩).
  4. Choose how back parts are shown with ⑬ Display Mode and ⑭ Occluded Style in "Occluded Display Mode."
Good to Know
  • While "Optimization Preset" in "Feature Optimization" is "Standard," "Lightweight," or "Lightest," back parts do not appear when X-Ray is off (because "X-Ray Off: Hide Occluded Color" is turned on). Return to "Highest Quality," or turn that item off.
  • Shortcut keys are not registered automatically. When you want one, "Copy" the "Registration ID" under "How to add a shortcut" and register it yourself.
  • Highlighting the object under the mouse in Object Mode is done by "Object / Sculpt Hover Color." Turn it on with "Object / Sculpt Hover" in "Always-on Toggles."

Settings in detail: 5-4. Mesh and Curve Display, 5-5. Vertex Settings, 5-9. Occluded Display Mode

2-2. See the Proportional Editing Range by Color (Proportional Display)See It in Figures

Displays the strength of influence of proportional editing (a feature that smoothly moves the area around the selection along with it) in color. The selected spot is red, changing to green and then blue as you move away, and nothing is colored outside the range. Because you can see how far and how much things will move before you move them, it is easier to decide "Radius." It can be used with meshes, curves, lattices, object origins in Object Mode, and UV editing. The three figures below are an example with one vertex on top of Suzanne's head selected.

How to Use
  1. In Edit Mode, select the vertex you want to move.
  2. In "Proportional Display" > "Settings," click ⑨ "Enable" to turn on proportional editing.
  3. Set "Proportional Display" in "Always-on Toggles" to "On."
  4. Change ⑩ "Radius" while watching the colored range to decide on it.
Good to Know
  • Both "Proportional Display" in "Always-on Toggles" and proportional editing must be on for the display to appear. "Mesh and Curve Display" can stay "Off."
  • The display in the UV Editor is based only on the UVs selected in the UV Editor.
  • "Connected," "Projected (from View)," and "Falloff Type" can also be changed from here (they appear when proportional editing is on).

Settings in detail: 5-15. Proportional Display

2-3. Find Trouble Spots in a Shape by Color (Topo Check)See It in Figures

Highlights, by color, the mesh edges and faces that deserve attention. Just by turning on the check, UV seams show up in light blue and edges that are not closed, such as the rim of a hole (non-manifold), show up in red; and when you turn on "Show Ngons," faces with 5 or more edges (N-gons) are filled in light pink. The colors of the other quad and triangle faces do not change, so only the spots you should look at stand out. Turn it on only when tidying a shape or inspecting it.

How to Use
  1. Enter Edit Mode and set "Mesh and Curve Display" in "Always-on Toggles" to "On" beforehand.
  2. Open "Topo Check" in "Other Tools" and turn on the check box at ④.
  3. From the edge types at ⑥ and the face types at ⑧, turn on only what you want to see ("Show Ngons" when looking for N-gons).
Good to Know
  • Appears only when "Mesh and Curve Display" is "On." No colors appear while "Optimization Preset" is "Lightest."
  • For edges that are selected, the selection color takes priority.
  • Turning off the types you do not need makes things easier to see.

Settings in detail: 5-17. Topo Check

4. Where to Find It

All features are in a single panel in the "Smart Overlay" tab of the 3D Viewport Sidebar (N panel). The same "Smart Overlay" tab also appears in the Sidebar of other editors, such as the Image Editor and the Node Editor. No items are shown in the add-on settings in Preferences.

Editors3D Viewport, Image Editor (UV Editor), Node Editor, Video Sequencer, Movie Clip Editor, Dope Sheet, Graph Editor, NLA Editor, Text Editor, File Browser, Spreadsheet
TabSmart Overlay
ModeObject Mode, Edit Mode, Sculpt Mode, and others (the modes you can use differ by feature)
  1. For installation, Japanese localization, how to open the N panel, and how to use the "?" help button, see the relevant chapter of the SmartTools Overall Specification.
  2. Open the Sidebar in the 3D Viewport and click the "Smart Overlay" tab.
  3. The panel is divided into 7 section headers, each enclosed in a frame ("Always-on Toggles," "Feature Optimization," "Mesh and Curve Display," "High-Precision Outline," "UV Overlay," "Proportional Display," and "Other Tools"). Click the triangle to the left of a section header to open or close it.
  4. First open "Always-on Toggles" and set the features you want to use to "On." Features left at "Off" are not displayed on screen.

6. Common Tasks

Make the Vertices and Edges You Are Editing Stand Out

While modeling, give selected vertices and edges an easy-to-see color and size

  1. Select a mesh and enter Edit Mode.
  2. In the "Smart Overlay" tab, open "Always-on Toggles" and set "Mesh and Curve Display" to "On."
  3. In "Mesh and Curve Display" > "Vertex Settings," turn on the check box for "Edit," and set the "Selected Color" color and "Vertex Size(px)."
  4. In "Edge Settings," set "Selected Color" and "Edge Size(px)" in the same way.
  5. When you want to see only vertices and edges, turn off "Edit" in "Face Settings."

Result: The selected vertices and edges are displayed in the color and size you set.

See Back-Side Vertices Without Turning On X-Ray

Display vertices and edges hidden behind front faces in a faint style

  1. In "Always-on Toggles," set "Mesh and Curve Display" to "On."
  2. Open "Mesh and Curve Display" > "Occluded Display Mode."
  3. Make sure the "Display Mode" field is set to "Always" (it is "Always" from the start).
  4. In "Occluded Style," choose something like "Fade" or "Thin," and set the intensity with "Occluded Alpha Multiplier."
  5. Make sure "Occluded Color" is checked in "Vertex Settings" and "Edge Settings."
  6. Also make sure "X-Ray Off: Hide Occluded Color" in "Feature Optimization" is off (it is off in the initial "Highest Quality." Choosing "Standard," "Lightweight," or "Lightest" turns it on, and the back-side colors do not appear while X-Ray is off).

Result: Even with X-Ray left off, the hidden parts are displayed faintly.

Find Modeling Problems All at Once

Find N-gons and hole rims (non-manifold edges) by color

  1. Select a mesh and enter Edit Mode.
  2. In "Always-on Toggles," set "Mesh and Curve Display" to "On." Topo Check is drawn on top of this overlay.
  3. If "Optimization Preset" in "Feature Optimization" is "Lightest," change it to another preset (with "Lightest," the colors for this check do not appear).
  4. Open "Other Tools" > "Topo Check" and turn on "Enable Topology Checks."
  5. Turn on "Show Ngons" under "Face" and "Show Non-Manifold" under "Edge."
  6. Turn off the types you do not need to make things easier to read.

Result: N-gons are filled in light pink, and non-manifold edges appear in red.

Measure and Display the Distance Between Two Vertices

Place a dimension line and value in the viewport

  1. Set "Smart Measure" in "Always-on Toggles" to "On."
  2. Enter Edit Mode on a mesh and select two vertices.
  3. In "Other Tools" > "Smart Measure" > "Smart Measure Tools," click "Segment."
  4. Change the number of digits and so on with "Precision" in "Items."

Result: A distance measurement is displayed between the two vertices.

See the Proportional Editing Range by Color

Check how far the influence reaches before you move anything

  1. Set "Proportional Display" in "Always-on Toggles" to "On."
  2. In "Proportional Display" > "Settings," turn on proportional editing with "Enable."
  3. Set the range with "Radius."
  4. Adjust the look with "Heatmap Opacity" and "Gradient Colors" in "Display Settings."

Result: The affected range is displayed in colors that match its strength.

Check a Shape as a Silhouette

See only the outline of the selected object

  1. In the 3D Viewport, select the object you want to check.
  2. In "Other Tools" > "Silhouette Mode," turn off "All Objects."
  3. Click the button in the "Silhouette Mode" row of "Always-on Toggles" to make it "On."
  4. When you are done checking, click the same button again to make it "Off."

Result: Only the selected object is displayed as a black silhouette on a white background. Setting it to "Off" returns the original display.

Assign a Shortcut Key to Toggle an Overlay

Turn "Mesh and Curve Display" on and off with a single key

  1. At the very bottom of "Mesh and Curve Display," under "How to add a shortcut," click the "Copy" button for the "Registration ID."
  2. In Blender, open "Preferences" > "Keymap" > "3D View."
  3. Add a new item, paste the copied text (do not change the text), and assign any key you like.

Result: You can turn the overlay on and off with the key you assigned.

7. Troubleshooting

I changed a setting, but nothing appears on screen.
Check that the feature is "On" in "Always-on Toggles." A "Off" feature is not displayed even if you change its settings.
There is no entry for this add-on in the add-on settings in Preferences.
All settings are changed in the "Smart Overlay" tab of the Sidebar. The add-on is designed not to show any items in Preferences.
No shortcut keys are registered.
This add-on does not register shortcut keys automatically. Click the "Copy" button for the "Registration ID" under "How to add a shortcut" in each section header, and register it yourself in "Preferences" > "Keymap."
The display is slow.
Set "Optimization Preset" in "Feature Optimization" to "Lightweight" or "Lightest." Set features you do not use to "Off" in "Always-on Toggles."
Are my changed settings saved?
If "N-panel State Save" in "Always-on Toggles" is "On," settings are saved immediately when you change them. When it is "Off," only the state at the time you disabled it is saved, and settings you change after that are not saved.
The contents of Smart Measure and Silhouette Mode do not appear.
They appear only when there is an active object, in the 3D Viewport Sidebar. Select one object.
The inside of "Items" in Smart Measure is empty.
The contents of "Items" appear only when an object that has measurements is selected. First create a measurement with "Smart Measure Tools," and then select that object.
Nothing happens when I click a Smart Measure button.
Each button has modes in which it can be used. "Segment," "Angle," "Arc," "Label," "Area," "X," "Y," and "Z" are used in Edit Mode, and "Annotation," "Link," and "Origin" are used in Object Mode. Also check the number of vertices or objects you have selected.
I click "Render" in Smart Measure, but no image is created.
It cannot be created if the scene has no camera. Add a camera and then click it. Open the created image in the Image Editor to view it.
When I turn off Silhouette Mode, does the display go back to the way it was?
Yes. It remembers the shading and overlay state from before the switch and restores it when you set it to "Off."
The Topo Check colors or the back edges suddenly stopped appearing.
Check "Optimization Preset" in "Feature Optimization." With "Lightest," the Topo Check colors do not appear. With "Standard," "Lightweight," and "Lightest," the colors of back edges do not appear while X-Ray is off. Returning to "Highest Quality" brings both back.

For problems common to every add-on, such as an add-on not appearing or the interface language not changing, see "Troubleshooting" in the SmartTools Overall Specification.

8. Glossary

Overlay
A supporting display drawn on top of the screen, such as the 3D Viewport. It does not appear in ordinary rendered images.
Occlusion
The state of being hidden behind a front face and not visible from the current viewpoint.
X-Ray
A Blender display that makes objects semi-transparent so you can see the back side too.
Hover
Resting the mouse cursor over something without clicking.
Depth Offset
An adjustment that draws dots and lines slightly toward the front to keep them from flickering when buried in faces.
Anti-Aliasing
Processing that makes the jagged edges of diagonal lines less noticeable so they look smooth.
LOD
A mechanism that changes the level of detail of processing according to how detailed an object is.
Topology
How the vertices, edges, and faces of a mesh are connected.
N-Gon
A face that has 5 or more edges.
Non-Manifold
Edges with unusual connections, such as edges that are not closed, like the rim of a hole, or edges where 3 or more faces meet.
Seam
An edge specified as a cut when unwrapping UVs.
Crease
A value for how sharply an edge is kept when subdividing.
Bevel Weight
A per-edge value for how much bevel (corner chamfering) to apply.
Proportional Editing
A Blender feature that, when you move a selection, also moves the surrounding area smoothly along with it according to distance.
Heatmap
A map that shows the strength of values through differences in color or intensity.
Local View
A Blender display switch that shows only the selected objects in the 3D Viewport.
Preset
A combination of settings saved under a name. Choose one and apply it to get the same settings.
Cache
A mechanism that keeps display data once it has been built and reuses it to lighten processing.

Limitations and Notes

  • Shortcut keys are not registered automatically. Copy the "Registration ID" with the "Copy" button and register it yourself in "Preferences" > "Keymap."
  • No items are shown in the add-on settings in Preferences. Settings are changed only in the "Smart Overlay" tab of the Sidebar.
  • A feature that is "Off" in "Always-on Toggles" is not displayed even if you change its settings.
  • The contents of "Smart Measure" and "Silhouette Mode" appear in the 3D Viewport Sidebar only when there is an active object.
  • The contents of "Items" in Smart Measure appear only when an object that has measurements is selected.
  • Each Smart Measure measurement button has fixed modes in which it can be used (Edit Mode / Object Mode) and a fixed way of selecting.
  • "Render" in Smart Measure cannot be used if the scene has no camera.
  • When Silhouette Mode turns only the selected objects into a silhouette, it uses Local View. When Local View cannot be used, all displayed objects become a silhouette.
  • The "Lightest" optimization puts view responsiveness first and omits the color of hidden parts, the Topo Check colors, curves, lattices, and the shape after modifiers.
  • Settings you change while "N-panel State Save" is "Off" are not saved. When you restart Blender, it returns to the state at the time you disabled it.
