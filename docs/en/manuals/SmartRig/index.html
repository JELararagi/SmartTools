About this tool

SmartRig Suite safely calls Auto-Rig Pro (a separately installed add-on that builds rigs automatically) and adds the finishing tools it lacks. A rig is the skeleton that lets a character move. SmartRig Suite can fix collapsing joints, set up the face and eyes, build bone chains for hair and clothing, bake secondary motion, and run various checks. In the Sidebar's "Smart Rig" tab, the section headers run in work order from "1. Setup and Parts" to "6. Animation". Work from top to bottom and the rig for a new character is finished. For installation, localization, how to open the N panel (Sidebar), and how to use the "?" help button, see the relevant chapter of the SmartTools Overall Specification.

1. What This Add-on Does

A companion add-on that lines up the whole Auto-Rig Pro rigging process in one panel, in order, from preparation to baking secondary motion and checking the motion.

  • See at a glance whether the external tools (Auto-Rig Pro, Rig Tools, Proxy Picker, AI_win) are available
  • Choose the rig and body mesh to work on, and find problems with a pre-check
  • Split a character into parts (outfits) by collection, and show, hide, or delete them together with their bones
  • Call Auto-Rig Pro's Add Reference Rig, marker guessing, detection, Match to Rig, and Bind after checking the prerequisites
  • Lift the whole character by the height of the shoe soles
  • Change the size of a finished rigged character without rebuilding it
  • Set up auxiliary bones so the skin does not collapse when elbows, knees, and wrists bend
  • Edit vertex weights (how strongly each bone affects a vertex) numerically and audit their quality
  • Prepare the eye rig, eyeball merging, eyelid pivots, the range of influence on the face, corrective shape keys, and eyelid drop shadows
  • Build bone chains for hair and hanging parts, and merge outfits using the skin weights
  • Add strip bones to the hem of skirts and jackets and make them avoid the legs
  • Fit collision capsules to the body and bake chain motion into keyframes
  • Add a cloth (fabric simulation) option to skirts
  • Switch between IK and FK while keeping the pose, and test the rig with motion capture to find weak spots
  • Assign, audit, and export Proxy Picker mappings
When to Use It
  • Build a rig for a new character, covering body, face, hair, and outfit, with Auto-Rig Pro
  • Fix collapsing when elbows or knees are bent deeply
  • Bake hair and strap motion into the animation so it can be exported to other software
  • Switch visibility part by part to change outfits
  • Run motion capture clips to find the weak spots of the rig

2. Key Features

This chapter walks through the features unique to this add-on, using numbered callouts on each figure. The numbers in a figure match the numbered list below it. Click a figure to enlarge it. Each individual setting is described under its own heading in Chapter 5.

2-1. Select a Part and Click to Build a Bone ChainTop Feature

To add bones to a jiggling part, you normally have to place bones one by one, bind them to the rig, and assign weights. With "Build Chain on Selected Part", you just select one part, such as a strap, braid, or hem, and click "Build Chain". A chain of bones is built along the part, the binding to the rig and the weights are done together, and the jiggle settings are remembered by the chain. Joints are placed at the breaks of the mesh and never inside rigid parts. When there are many hair strands, "Build Hair Chains" turns them all into chains at once, and long strands have the same number of bones, so one master can move them together.

How to Use
  1. Put the rig in "Target Rig Armature" under "1. Setup and Parts" > "Workflow Targets".
  2. Select the part's mesh (in Edit Mode, select vertices to use only that portion).
  3. Decide ① the shape, ② the name, ③ "Bones", ④ "From", and ⑤ the jiggle.
  4. Choose ⑥ how to place the joints, and click ⑧ "Build Chain".
  5. Rotate the chain bones to check that the part bends along with them.
  6. When there are many hair strands, set "Pattern", "Bones", and "Parent" in "Hair & Dangling Parts" and click ⑫ "Build Hair Chains".
Good to Know
  • The bone that vertices without weights go to is the nearest deforming bone if the "From" is a control bone that does not deform, or the bone near the top of the part if it is empty. The report shows which bone it is.
  • Before rebuilding with the same name, click ⑨ "Remove Chain". If you build two under one name, the first one is no longer tied to anything.
  • The default "Name Pattern" (tail[A-Z]) matches names such as tailA and tailS. For strands with other names, rewrite it.

Settings in detail: 5-29. Chain on Selected Part, 5-27. Hair & Dangling Parts

2-2. Bake Jiggle into Ordinary KeyframesSee It in Figures

"Bake Jiggle" calculates the jiggle of the chains and writes it to the bones as ordinary keyframes. What remains in the file is bone animation, so it plays without this add-on and can be exported or edited. Just click the button after adding body animation, and parts such as the tail lag and jiggle with the momentum of the motion; if you turn on "Stop at the floor", they do not pass through the floor.

How to Use
  1. Add the body animation and fit the capsules.
  2. If needed, choose chains with ② "Include Selected" and "Leave Out Selected" (you can also enter chain names in ①).
  3. Set ⑥ "Stop at the floor" and ⑦ "Height".
  4. Click ⑧ "Bake Jiggle".
  5. Play it and compare with ③ "Stop Swing" and ④ "Play Swing".
Good to Know
  • If you select a chain bone in Pose Mode, only that chain is baked; if nothing is selected, all chains included in the bake are baked.
  • When you change a value in the ⑫ box, it takes effect the next time you bake.
  • "Stop at the floor" has no effect on a chain that is already below "Height" by more than 10% of the chain length on the first frame of the bake, and this is shown in the report.
  • Long animations take time. Do not touch Blender while it is baking.

Settings in detail: 5-38. Bake Jiggle, 5-39. Selected Chain (Header Is the Chain Name)

2-3. Switch Between Baked Jiggle and Hand Keys for Each PartSee It in Figures

For each named part, one button switches between using the baked jiggle and moving only with hand-keyed keys. Registering a part creates a row, and the chosen state is saved in the file. Hand-keyed keys are never overwritten, so in the same scene you can use parts whose jiggle you want to keep alongside parts you want to move by hand.

How to Use
  1. Enter the part's chain in "Chains" of "Bake Jiggle" (for example: *tail*), or select the bones of each chain in Pose Mode.
  2. Enter the part name in ① and click "Register". Repeat for each part.
  3. Bake with the ③ key button in the row. If you already baked with "Bake Jiggle", that jiggle moves into the layer as it is, so you do not need to bake again unless you changed the body motion.
  4. Click ② "Simulation" or "Hand-Keyed", then play it and check the motion.
Good to Know
  • Clicking "Register" with the same name replaces it, and the layers and baked jiggle of chains you did not enter are deleted.
  • If you enter the chain of another part, that chain moves to this one (the row of a part that has lost all its chains is deleted).
  • If "Action slot unknown: nothing can be switched" appears, assign the rig's action first.

Settings in detail: 5-40. Parts: Sim or Hand

5-9. Shoe Sole Lift

Lifts a character built to stand barefoot on the floor (Z = 0) by the height of the shoe soles. It attaches a driver (a mechanism that calculates a value automatically) to the rig's parent, so no bones are added.

Location"2. Body Rig (Auto-Rig Pro)" > "Shoe Sole Lift"

ItemWhat it does
Status rowShows one of "Lifted", "Cleared", or "Not set up", and the measured height. When no Auto-Rig Pro rig has been decided, only "Choose an Auto-Rig Pro rig." is shown and no buttons appear.
"Margin mm"The height added by "Measure" (default 0).
"Height mm"The height used by "Lift". With the default of -1, the measured sole height is used.
"Lift Projectors"Also lifts the UV projectors that are outside the rig's parent (on by default).

"Lift"Lifts everything. When "Height mm" is less than 0 (default -1), it lifts by the measured sole height; when it is 0 or more, it lifts by that value.

  3. Click "Lift".
  4. Click "Clear" before working on the rig, then lift again afterward.

6. Common Tasks

Build a Body Rig for a New Character

Create a body rig with Auto-Rig Pro and bind the mesh to it

  1. In "1. Setup and Parts", check that the status line shows a check mark for Auto-Rig Pro.
  2. Select the base body mesh and click "Use Current Selection" in "Workflow Targets" (there is no rig yet, so "Target Rig Armature" can stay empty). Then click "Run Preflight".
  3. In "Reference Rig & Markers", choose a preset and click "Add Reference Rig".
  4. Place the markers. When "Required markers ready" appears, click "Run Detection", then click "Match Reference to Rig".
  5. When the production rig is made, select the rig and the mesh and click "Use Current Selection" again.
  6. In "Bind", select the mesh and click "Bind".
  7. In "Auxiliary Bones (All)", click "Set Up All".

Result: The body moves with the bones, and the elbows and knees resist collapsing even when bent deeply.

Build Chains on Hair and Bake the Jiggle

Keep the hair jiggle in the animation as keyframes

  1. In "Hair & Dangling Parts", set "Bones" and "Parent", and click "Build Hair Chains".
  2. In "Collision", choose the outer surfaces and click "Fit Capsules".
  3. Check that the body animation is in place.
  4. In "Bake Jiggle", click "Bake Jiggle".
  5. Play it and compare with "Stop Swing" and "Play Swing".

Result: Keyframes that make the hair sway and settle are added, and it plays even without the add-on.

Swap Outfits Part by Part

Show and hide the outfit meshes and bones together

  1. Put each outfit part in its own collection and give the names some common text.
  2. Enter that text in "Marker" in "Parts & Outfits".
  3. Check the list of parts with "Audit Parts".
  4. In "Parts", choose a collection and click "Show" or "Hide".

Result: The outfit meshes and their control bones appear and disappear together.

Change a Character's Height

Change the size without rebuilding the rig

  1. Save the file.
  2. In "Character Size", choose "Target Height".
  3. Select the mesh, click "Measure", and enter the "Target Height (mm)".
  4. Click "Check" and read the report.
  5. Click "Resize".

Result: The character reaches the target height while keeping its modifiers and weights.

Test the Rig with Motion Capture

Find where the rig collapses or stretches

  1. In "Motion Capture", choose the clip file.
  2. In the skeleton field, choose the one that matches the clip.
  3. Click "Load & Bake".
  4. Click "Check Motion" and check the vertex groups it reports.

Result: You learn the names of the vertex groups that cause problems during the motion, which narrows down where to fix.

7. Troubleshooting

Can I use it without Auto-Rig Pro?
Many functions, such as the body rig, eyes, and IK/FK, call Auto-Rig Pro, so you need to install and enable it separately. When it is disabled, a warning line with a triangle warning mark appears in the section, and the buttons that call Auto-Rig Pro are grayed out. Proxy Picker and AI_win are optional.
A button is grayed out and I cannot click it.
The external tool that the button uses is not enabled. Check the status lines in "1. Setup and Parts", enable the tool you need, and then click "Refresh External Status".
I clicked a button by mistake. Can I undo it?
You can undo most buttons with Ctrl+Z right after clicking them. Some of the buttons that build things also have a matching button, such as "Clear" or "Remove". For operations that rewrite the mesh, such as smoothing weights, restoring from a saved backup is the safest way.
Can I use "Match Reference to Rig" on a finished character?
Do not use it. Match to Rig rebuilds the generated bones, so manual fixes such as the eyelid pivot are erased.
Are the panel settings saved?
If "N-panel State Save" in "Always-on Toggles" is on, the values come back when you restart or open a file.
Where can I read a detailed explanation of each button?
The "?" at the right end of each section header has a detailed explanation of that section. For how to use the "?", see the SmartTools Overall Specification.

For problems common to every add-on, such as an add-on not appearing or the interface language not changing, see "Troubleshooting" in the SmartTools Overall Specification.

8. Glossary

Rig
The whole skeleton and control system used to move a character.
Armature
A Blender object that holds a group of bones.
Auto-Rig Pro
A separately installed add-on that automatically builds a character rig. SmartRig Suite calls it.
Reference Rig and Reference Bones
Draft bones used to decide the bone positions before the production rig is built.
Marker
A mark that shows the position of a key point on the body, such as the chin or wrist. Auto-Rig Pro uses it as a clue for placing bones.
Match to Rig
An Auto-Rig Pro function that rebuilds the production rig from the reference bones.
Bind
Tying a mesh to bones so that it moves with them.
Weight
The amount by which each bone moves a vertex, expressed from 0 to 1.
Vertex Group
A container that holds a set of vertices and their weights. There is one for each bone.
Driver
A Blender mechanism that automatically calculates a value from other values.
Shape Key
A mechanism that stores differences in mesh shape and blends them by a percentage.
Bake
Writing a calculated motion as ordinary keyframes.
Collision and Capsules
Capsule-shaped collision ranges placed so that jiggling parts do not sink into the body.
Cloth
A Blender simulation that calculates the motion of fabric.
IK/FK
IK is a method where moving the hand or foot adjusts the whole arm or leg; FK is a method where you rotate from the root in order.
Kilt (Strip Bones)
An Auto-Rig Pro controller system arranged in vertical columns on a skirt or similar garment.
Proxy Picker
A separate add-on that handles substitute shapes (proxies) for selecting bones.
AI_win
An external AI runtime that Auto-Rig Pro uses to estimate marker positions.

Limitations and Notes

  • The body rig, eyes, IK/FK, Kilt, and so on cannot be used unless the separately installed Auto-Rig Pro is enabled. SmartRig Suite does not include the code of Auto-Rig Pro, Proxy Picker, or AI_win.
  • Marker estimation with AI_win can run only on Windows x64.
  • If you use Match to Rig on a finished character, your manual fixes to the generated bones are erased.
  • If you change the structure of the rig, you need to bind again and check the weights. Binding again replaces hand-painted weights.
  • Operations that smooth weights and "Clear Contact" rewrite the mesh, so "Clear" does not undo them.
  • Baking jiggle is not a live simulation. If you change the body animation, you need to bake again, and long animations take time.
  • Cloth must be played from the start frame, and it is a heavier process than bones.
  • No keymap (shortcut keys) is registered. All operations are done with the buttons in the panel.
