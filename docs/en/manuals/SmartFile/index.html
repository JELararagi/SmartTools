Version 1.0.0 / November 19, 2026 / For Blender 5.1.2

About this tool

SmartFile Suite is an add-on that handles Blender file work in one place. From a single panel you can bring in data from other .blend files, inspect and reconnect links (a way of loading data by referencing another file), collect and export external files, and create a restore point (a save you can return to later) before you start working. Each section header in the panel can be collapsed. From the top, the panel lists "Always-on Toggles", "Current Source", and "Quick Sources", followed by seven categories: "Link", "Append", "Import", "Export", "Preview", "History & Restore", and "Other". For how to use the "?" help button at the right of each section header, see the "? Help" chapter of the SmartTools Overall Specification.

1. What This Add-on Does

A tool that brings importing files, checking links, exporting, review, and history and restore together in a single Sidebar panel.

  • Choose another .blend file (the source) and bring its data into the current scene.
  • Quickly switch to a recently used source or to a source you added to your favorites.
  • Search the search roots for textures and links that can no longer be found because their location changed, and reconnect them.
  • Check the status of linked libraries (other files being referenced), and review the candidate reconnections before applying them.
  • Create a bundle that gathers external files such as textures into a single folder.
  • Run an audit (a check for problems) and a final review before exporting or handing off your work.
  • Create a manual restore point before you work, then pick one from the list later to go back. Rolling Autosave (an automatic backup that replaces the oldest copies once a set number is reached) is also available.
  • Crash Recovery extracts the state of another Blender session that crashed and saves it as a new file.
  • Undo Load Diagnostic measures how long Undo takes.
  • You can call MAX (.max) import from "Import". Using the bundled tools, you can also call importing and exporting for 3DS, DXF, STL, and more from the integrated tools section header inside each category.
  • Filter objects by conditions such as custom properties and display name labels in the 3D Viewport.
When to Use It
  • When you want to bring a small prop or material made in another .blend into the current scene.
  • When links broke after you moved a folder and you want to reconnect them.
  • When you want to gather external files such as textures in one place to hand off to someone.
  • When you want to create a point to return to before a big change, and go back if it fails.
  • When Blender crashed and you want to retrieve the state from just before.
  • When Undo is slow and you want to check how much data you have.

2. Key Features

This chapter walks through the features unique to this add-on, using numbered callouts on each figure. The numbers in a figure match the numbered list below it. Click a figure to enlarge it. Each individual setting is described under its own heading in Chapter 5.

2-1. Find and Fix Broken ReferencesTop Selling Point

When you move a folder of textures or other files, objects that use files Blender cannot find turn pink, and you end up searching for them again one by one. The "File Pipeline" window inspects the external files your file uses and shows the number of files that cannot be found, the number of absolute paths, and a score on one screen. "Resolve Missing References" searches the search root for the same file, with scores, and reconnects only the ones it is sure about.

How to Use
  1. In the "Smart File" tab of the 3D Viewport Sidebar (N key), open the "Link" category, and open the window with the top button of the "File Pipeline" section header.
  2. Click "Pipeline Preflight" at ④ and look at the score at ① and the number of missing files at ②.
  3. Enter the folder you moved the files to in "Search Root", and turn on "Apply Changes" (see the figure in the next section, "Check First, Then Rewrite").
  4. Click "Resolve Missing References" at ⑤.
Why It Is Useful
  • Candidates get a score, and candidates lower than "Confidence Threshold" are not reconnected. There is little risk of a different file with a similar name being linked by mistake.
  • When "Apply Changes" is off, it only saves a proposal and the paths do not change.
  • Before handing off to someone, click ⑥ to finish everything from diagnosis to file collection and verification in one go.

Settings in detail: 5-6. File Pipeline Window, 5-7. File Pipeline Window: Settings

2-2. Check First, Then Rewrite with Apply ChangesSafety Mechanism

Every feature that rewrites paths changes the inside of the file only when "Apply Changes" is on. It is off at first, and while it is off, features only show proposals and results in the report. You check the proposal, then turn it on and click, so unexpected rewrites are prevented. The two images below compare the same "Apply Repath" clicked with it off and clicked with it on.

How to Use
  1. Turn on "Show Advanced", then enter the original folder in "Replace From" at ⑤ and the new folder in "Replace To".
  2. With "Apply Changes" at ③ still off, click "Apply Repath" and check the proposal in "Latest File Pipeline Report".
  3. If the proposal looks good, turn on "Apply Changes" and click "Apply Repath" again.
Good to Know
  • "Apply Changes" takes effect for the features that change paths (the path write-back of "Resolve Missing References", "Apply Repath", "Make Paths Relative", "Apply Version Plan", "Texture Extension Swap", and "Collect Package") and for "Edit Linked Library". Other features work regardless of this switch.
  • "Apply Repath", "Make Paths Relative", and "Apply Version Plan" warn you when "Apply Changes" is off.
  • Input fields such as ⑤ and ⑥ appear only when "Show Advanced" is on.
  • If you turn on "Use Relative Paths" at the right side of the same area, the paths written back become relative paths when the file has been saved.

Settings in detail: 5-7. File Pipeline Window: Settings

2-3. Restore Points and Crash RecoverySafety Mechanism

If you click "Create Manual Restore Point" before a big change, you can return to that state from "History Browser" even if something goes wrong. When another Blender session crashes, "Crash Recovery" extracts its state as a new file and opens it after confirmation. The crashed Blender and the original file are not changed.

How to Use
  1. In the "Smart File" tab of the 3D Viewport Sidebar (N key), open the "History & Restore" category.
  2. Before a big change, enter a name at ① and click "Create Manual Restore Point" at ②.
  3. When you want to go back, open "History Browser", click the row you want to return to at ⑤, then click "Restore Selected" at ⑥ and click "OK" in the confirmation window.
  4. When another Blender session crashes, look for candidates with ⑦ or ⑧ of "Crash Recovery", select one in "Recovery Candidates", and click "Recover Latest State" at ⑨.
Things to Watch Out For
  • When you restore, the whole file is replaced with the state at the time it was saved, so changes made after that are not kept. After restoring, the file that is open is a file inside the history folder.
  • When there is no file that can be restored directly for the selected row, the nearest earlier restore point is used. Before restoring, check the time and contents in "Selected Snapshot".
  • Turn on timed restore points and autosaves in "Automatic Protection". While both are off, nothing is saved automatically.

Settings in detail: 5-16. History Summary, 5-17. History Browser, 5-21. Crash Recovery, 5-19. Automatic Protection

It is in the "Smart File" tab of the 3D Viewport Sidebar (N panel). The panel header is "Smart File". The same panel also appears in the Sidebar of the Image Editor, Node Editor, Dope Sheet, Graph Editor, NLA, Video Sequencer, Movie Clip Editor, File Browser, Spreadsheet, and Text Editor. If you have set the display for each editor in Smart Tools Manager, that setting is followed.

6. Common Tasks

Import Data from Another .blend

Bring things from another file into the current scene in an editable form.

  1. Open the "Smart File" tab in the Sidebar.
  2. Open the "Append" section header and click "Smart File...".
  3. In the file selection window, select the .blend to import from.
  4. In the list that opens, select the data you want to import and import it.
  5. If it is a file you use often, add it to your favorites with "Add Favorite" in "Quick Sources".

Result: The selected data comes into the current scene. From next time, you can quickly select it from "Recent Sources" or "Favorite Sources".

Create a Return Point Before a Big Change

Make sure you can return to the state before the change if something goes wrong.

  1. Open the "History & Restore" section header.
  2. In "Checkpoint" under "History Summary", enter an easy-to-recognize name.
  3. Click "Create Manual Restore Point".
  4. When you want to go back, open "History Browser" and click the row you want to return to, to select it.
  5. Check the time and contents in "Selected Snapshot", then click "Restore Selected" in "History Browser".
  6. Check the contents in the confirmation window, then restore.

Result: The state returns to the point you selected.

Reconnect Broken Links

Fix links that can no longer be found, for example after moving a folder.

  1. Open the "Link" section header.
  2. In "Linked Overview", check how the links are connected.
  3. Click "Relink" and check the paths that cannot be found and the candidate reconnections.
  4. Apply only the changes you know are correct.

Result: The links are reconnected to the correct files.

Collect External Files and Hand Them Off

Gather textures and other files in one place so they can be handed off.

  1. Open the "Preview" section header and check the state of external files with "Audit".
  2. Open the "Export" section header and click "Bundle".
  3. In the window that appears, check the destination and whether to create a copy of the .blend and a ZIP, then run it.
  4. Check the bundle you created with "Verify Bundle..." in "Preview".

Result: The external files are gathered into a single folder.

Reconnect Textures Whose Location Changed

Reconnect textures that turned pink after you moved a folder to the files in the new location.

  1. Open the "Link" section header, then open the "File Pipeline" section header.
  2. Click the top "File Pipeline" button to open the window.
  3. In "Search Root", enter the folder you moved the textures to.
  4. Turn on "Apply Changes".
  5. Click "Resolve Missing References".

Result: Only the files that have a reliable candidate are reconnected, and the pink in the 3D Viewport returns to the original textures.

7. Troubleshooting

There is a tab, but its contents are only section headers.
Most section headers are closed at first. Click a section header's name to open it.
"Measure Undo Speed" cannot be clicked.
Select one object and switch to Object Mode. If either is missing, it cannot be clicked. If it can be clicked but stops, check that a 3D Viewport is open and that animation playback and rendering are stopped.
"Add Favorite" cannot be clicked.
It cannot be clicked when no source is selected. First select a source with "Smart File..." in "Append".
No text appears even though I enabled "Viewport Labels".
By default, labels appear only on selected objects that have custom properties. Select an object and add a custom property, or click "Reporter: Advanced Controls" in "Integrated Advanced Controls" under "Preview" and, in the window that opens, turn off "Only selected" and "Tagged Only".
The paths do not change even after I click "Resolve Missing References" or "Apply Repath".
When "Apply Changes" in the "File Pipeline" window is off, it only creates a proposal and does not change the paths. Turn it on and click again. Even when it is on, "Resolve Missing References" does not reconnect candidates whose score is lower than "Confidence Threshold".
Where do I enter the replacement destination of paths and the extensions?
When you turn on "Show Advanced" in the "File Pipeline" window, the input fields "Replace From", "Replace To", "Source Extension", and "Target Extension" appear. "Apply Repath" rewrites the paths when "Apply Changes" is on. First click it with "Apply Changes" still off, or click "Preview Repath", to check the proposal.
Does using autosave make my PC slow?
In "Always-on Toggles", enable only the features you need. If you enable "Skip Unchanged Autosaves", nothing is saved while nothing has changed.
Do the panel settings remain after I close Blender?
If "N-panel State Save" in "Always-on Toggles" is enabled, they are saved and restored at the next startup. It is enabled from the start.
Sometimes a button is gray and cannot be clicked.
The conditions for using that feature are not met, or the feature cannot be used in the current state. If there is a "?" at the right of the button, click it to show an explanation.
Can I use it in other editors too?
The same SmartFile Suite panel also appears in the Sidebar of the Image Editor, Node Editor, and others.

For problems common to every add-on, such as an add-on not appearing or the interface language not changing, see "Troubleshooting" in the SmartTools Overall Specification.

8. Glossary

Source
The .blend file that data is brought in from.
Append
Copying data from another .blend and bringing it in. What you bring in can be edited freely.
Link
Using data from another .blend by referencing it without copying it. If you fix the original file, the change is reflected here too.
Library
Another .blend file that is referenced by a link.
Relink
Reconnecting a link that can no longer be found to the correct file.
Library Override
A mechanism that makes it possible to edit only part of linked data without changing the original file.
Path
A string that shows where a file is located.
Relative Path
A path written starting from the location of the .blend file. It is less likely to break when you move the whole folder.
Search Root
A folder that is searched when looking for files that cannot be found.
Bundle
External files gathered into a single folder.
Container
A group of data published with a version number.
Audit
Checking for problems.
Restore Point
A file saved at that point in time so you can return to it later.
Rolling Autosave
A backup that saves automatically and, once the set number is exceeded, replaces the oldest ones first.
Orphan Data
Data that is not used anywhere.
Undo
Reversing an operation.

Limitations and Notes

  • Undo itself is a mechanism of Blender, so this add-on cannot make it faster. "Undo Load Diagnostic" only measures time and shows the amount of data.
  • Data deleted by "Purge Orphan Data" cannot be recovered.
  • "Crash Recovery" searches only for other Blender sessions that can be judged to have crashed. The Blender you are using now is not a target.
  • Bundled import and export features are loaded only when you click their button (except for those enabled in the always-on toggles).
  • Buttons for features whose conditions are not met are gray and cannot be clicked.
  • When you restore with "Restore Selected", the whole file is replaced with the state at the time it was saved. Changes made after that are not kept. After restoring, the file that is open is a file inside the history folder, so to keep it in the original location, save it with "Save As...".
