SmartID Suite Manual

Version 1.0.0 / November 19, 2026 / For Blender 5.1.2

About this tool

SmartID Suite is an add-on that manages the identifying numbers and names you use in production in a single list. You register Object IDs, Material IDs, UV maps, color attributes, geometry attributes, vertex groups, selection sets, and more as rows (entries) in the list. A registered entry can be assigned to the selected objects with one button. Conversely, you can read IDs from existing objects and add them to the list. You can also inspect what is inside the selected objects and fix names and numbers on the spot. The list can be exported to a JSON file and imported into another file. The results remain as ordinary Blender data: pass indexes, materials, UV maps, attributes, and collections.

Give related parts a shared ID and check the assignment

This game controller has four dials and six pads. Give each group a number and a display color so that you can recognize assigned parts even when their starting colors are identical.

Follow the steps on the Blender screen

  2. Select the four dial objects. Under Assignment Settings choose Selected, enable Use Pass Index and Auto Color, and click Apply Entry. Repeat for the six pads using an entry named Pads, ID 33 and a teal color.
  3. Select just two pads and click Refresh Counts. For Pads the counts are 2 selected and 6 in the scene. Select Dial 1 and refresh Selection Inspector to confirm its ID of 17.

1. What This Add-on Does

An add-on that manages the IDs and channels you use in production (UV maps, attributes, groups, and more) in one list, so you can assign them to objects in bulk and inspect them.

  • Register and manage 12 types of entries, such as Object ID, Material ID, UV channel, and color attribute, in one list
  • Assign registered entries to the selected objects or to objects in the scene in bulk (apply), or remove them (unassign)
  • Select the objects, or the mesh elements (faces and vertices), that match an entry
  • Read the IDs and channels that already exist in the scene or in the selected objects and add them to the list (sync)
  • Inspect the IDs, material slots, UVs, attributes, and groups inside the selected objects in a list, and fix names and numbers on the spot
  • Create, activate, and delete UV maps, color attributes, and geometry attributes on meshes
  • Create materials with a color for each ID, selection collections, and View Layer AOVs
  • Overlay colored boxes and marks on the 3D Viewport to check what is assigned where (the data is not changed)
  • Validate the list for duplicates and missing items, and save the result as text
  • Export the list as JSON, import it, and export it as CSV
When to Use It
  • Keep the Object ID and Material ID numbers used for post-render compositing consistent across the whole file
  • Create UV maps or color attributes with the same name on multiple objects at once
  • Check in a list which IDs and UVs a received file contains
  • Save a set of decided IDs as JSON and use the same numbers in other shots or other files
  • Visually confirm that assignments are correct with the colored boxes in the 3D Viewport

2. Key Features

This chapter walks through the features unique to this add-on, using numbered callouts on each figure. The numbers in a figure match the numbered list below it. Click a figure to enlarge it. Each individual setting is described under its own heading in Chapter 5.

2-1. Register IDs in One List and Assign Them to the Selection with One ButtonTop Selling Point

Manage 12 types of identifying numbers and names, such as Object ID, Material ID, UV channel, and color attribute, in a single list in the Sidebar. A registered entry can be assigned to the selected objects with one button. The result remains as ordinary Blender data: pass indexes, materials, UV maps, attributes, and collections. Conversely, you can read IDs from existing objects and add them to the list. The list can be exported to a JSON file, so you can use the same numbers in other shots or other files.

How to Use
  1. Open the "Smart ID" tab in the Sidebar of the 3D Viewport (N key), choose a type with ① in "ID / Channel Library", and click "Add" at ②.
  2. Select the objects you want to assign to. To assign to faces only, select the faces in Edit Mode and set "Material Target" in "Assignment Settings" to "Selected Faces".
  3. Select the entry's row in the list and click "Apply to Selection" at ⑤.
  4. To check by color, set "Color" in "Viewport Shading" of the 3D Viewport to "Object".
Handy Points
  • When you receive a file that already has IDs assigned, "Sync from Scene" at ⑦ reads the IDs and channels in it into the list.
  • When you choose multiple rows with the checkboxes at the far left, ⑤ and ⑥ process the checked rows together.
  • "Write Blender Pass Index" in "Assignment Settings" is turned on from the start, so the numbers of Object IDs and Material IDs are also written to Blender's pass indexes. To remove them, click "Unassign from Selection".
  • Clicking "Select Elements" in "Selection / Assignment" reselects the faces that have a Material ID and the vertices of a vertex group.

Settings in detail: 5-2. ID / Channel Library, 5-4. Assignment Settings, 5-5. Selection / Assignment, 5-9. Check / Import / Export

2-2. Check What Is Assigned Where with Colored Boxes and Name Tags in the 3D ViewportSee It in Pictures

In the 3D Viewport, items with an ID are surrounded by a box in the entry's "Display Color", and a label (name tag) such as "Object ID: entry name" appears at the corner of the box. An ID assigned to faces is shown with small cross marks at the positions of those faces. You can see on screen which item or face has which ID without comparing against the list. This is only a visual check: it does not change material or mesh data, and it does not appear in render results.

How to Use
  1. In "Always-on Toggles", click the "Enable Overlay" button to set it to "On".
  2. Open "Visual Overlay" and turn on what you want to show from "Object Boxes" at ④, "Element Marks" at ⑤, and "Show Labels" at ③.
  3. To show boxes on all the objects in the scene, set "Library Match Scope" in "ID / Channel Library" to "Scene Objects" (with selection or active object, boxes appear only on the objects in that scope).
  4. To change the box color, select the entry in the list and change "Display Color" in "Selected Entry".
Handy Points
  • Boxes, labels, and marks are drawn only in the 3D Viewport and do not appear in render results. They do not change material or mesh data either.
  • If you set ① to "Inspector Items", the rows of the "Selected Object Inspector" list (UVs, attributes, and so on) can also be drawn. Rows without a display color get a color generated from their names.
  • "Opacity" and "Line Width" change the color strength and the line width of the boxes.

Settings in detail: 5-8. Visual Overlay, 5-1. Always-on Toggles, 5-3. Selected Entry

2-3. Inspect the Contents of Selected Items in a List and Fix Names on the SpotSee It in Pictures

Puts the IDs, material slots, UV maps, attributes, groups, and SmartID Suite records inside the selected objects into a single list. You can see right away which IDs and UVs a received file contains. Select a row to fix its name or ID number on the spot and write it back to the actual data. Rows such as attributes that must not be deleted become "Protected" and do not change even if you run a delete operation.

How to Use
  1. Select the objects you want to inspect, open "Selected Object Inspector", and click "Refresh Selection Data" at ①.
  2. Click the row you want to fix in the list to select it.
  3. Edit the name and ID number in the fields at ⑥, and click "Apply Item Settings" at ⑦.
Handy Points
  • Typing text in "Inspector Search" searches names, values, and notes. It matches both Japanese and Blender's English names.
  • When you set "Selection Inspector Auto Refresh" in "Always-on Toggles" to "On", the list is rebuilt every time you change the selection. It is "Off" at first, so click ①.
  • Clicking "Set from Active Smart ID" applies the settings of the entry selected in the Library list to this row's data only.

Settings in detail: 5-7. Selected Object Inspector, 5-1. Always-on Toggles, 5-2. ID / Channel Library

5-1. Always-on Toggles

This is where you turn on or off, one by one, the features that keep running in the background without pressing any button. Each time you click the button below an item name, it switches between "On" and "Off".

LocationIt is the topmost section header of the Smart ID tab. It is closed at first.

ItemWhat it does
N-panel State SaveDecides whether this tab's settings are saved to the settings file (Smart_ID_Suite.json) as soon as you change them. It is "On" at first.
Selection Inspector Auto RefreshWhen you change the object selection, the "Selected Object Inspector" list is rebuilt automatically, and the Library List is narrowed down again by the current selection. It is "Off" at first. When it is disabled, click "Refresh Selection Data" or "Selection Changed: Refresh".
Automatic Metadata CleanupWhen a file is opened or saved, automatically clears the temporary inspector rows and the SmartID Suite records (metadata) whose owner no longer exists. It is "Off" at first.
Enable OverlayDecides whether to draw colored boxes and marks for checking in the 3D Viewport. It is "Off" at first. How they are drawn is set in the "Visual Overlay" section header.
Note
If you set all of them to "Off", SmartID Suite has no processing that runs repeatedly in the background. Enable only the features you use.

5-2. ID / Channel Library

This is the central list of the add-on. You register each ID or channel as an "entry", one per row, and assign the selected entry to objects.

LocationRight below "Always-on Toggles". It is open from the start.

ItemWhat it does
Filter TypeNarrows down the types of entries shown in the list. Choose "All" to show everything. When you type text in the search field below, the list is narrowed down by searching entry names, channel names, UV map names, attribute names, group names, export tags, and notes. Rows hidden by "Filter Type" or the search are still targets of "Apply to Selection" and similar operations as long as they remain selected.
Library Match ScopeChooses what the rows shown in the list are based on. "Selected Objects" shows only the entries contained in the objects you have selected, and "Active Object" shows only the entries contained in the one active object. "Scene Objects" shows all registered entries. It is "Selected Objects" at first. Entries that have not been used anywhere yet are always shown. Render AOV rows belong to the view layer, so they are always shown too. Selected rows and checked rows stay in the list even if they are not part of the selection, because they are targets of the operation buttons. When there is neither a selection nor an active object, all entries are shown without hiding any. After you change the selection, all rows are shown until you click "Selection Changed: Refresh". The number on the right is the number of target objects.
New Entry TypeChooses the type of entry created by "Add". There are 12 types: "Object ID", "Material ID", "Map Channel", "UV Channel", "Color Attribute", "Geometry Attribute", "UDIM Tile", "Selection Set", "Render AOV", "Cryptomatte Tag", "Weight Group", and "Custom ID".
AddAdds a new entry of the chosen type to the end of the list and selects that row. The ID number becomes the next free number within the same type (different types can have the same number), and the name and channel name are assigned automatically according to the "Naming Profile".
List RowsFrom the left, each row shows the multi-select checkbox at the far left, the enabled checkbox, the type mark and ID number (3 digits), the name, and the match count. The type text appears to the right of the name when you widen the Sidebar. The match count is shown as "count in selection/total count" when there are target objects in the match scope. With "Scene Objects", only the total count is shown. The counts are numbers of items (for channel rows, the number of mesh channels). For a material row, it is the number of items that use that material. When the selection count is "-", it means the counts have not been refreshed since the selection changed. Locked entries get a lock mark. You can edit a name directly on its row (for a Material ID row that shows a material name, edit it in "Selected Entry"). Long names are truncated. Enable or disable an entry with the enabled checkbox on its row or with "Enabled" in "Selected Entry".
Icon Buttons Below the ListThese are the buttons without text lined up horizontally right below the list. From the left, they are delete entry (Delete Smart ID Entry), duplicate (Duplicate Smart ID Entry), move up and move down (Move Smart ID Entry), and recount (Refresh Smart ID Counts). Hover the mouse over them to see their names. Locked entries cannot be deleted. When the match scope is selection or active object, recounting adds, as rows, the IDs and channels that exist in the selected items but not in the list. The selected row does not change.
Selection Changed: RefreshA button that appears right below the list after you change the selection. Click it to recount with the current selection and hide the rows that do not exist in the selected items. IDs and channels that exist in the selected items but not in the list are added as rows. The selected row and the checked rows stay even if they do not exist in the selected items (the count appears like 0/1). If you click "Apply to Selection" in this state, the entry of that row is assigned. If you select another row or uncheck, the rows that remained are hidden.
Selected / Select Visible / Clear Selection / Delete SelectedThe number of rows chosen with the checkboxes at the far left (multi-select), and the operations on them. "Select Visible" checks all the rows currently visible. "Clear Selection" unchecks all of them. "Delete Selected" deletes the checked rows at once. Locked rows are skipped.
Apply to SelectionAssigns the selected entry to the objects in the "Target Scope" of "Assignment Settings". Disabled or locked entries are not assigned.
Select by EntrySelects the objects that match the selected entry.
Sync from SelectionChecks the objects in the "Library Match Scope" (selected or active objects) and adds the IDs, channels, attributes, and groups that are not yet in the list as entries.
Sync from SceneChecks the whole scene and adds the IDs, channels, attributes, and groups that are not yet in the list as entries.
ValidateChecks the list for duplicate IDs, empty names, missing channels, and so on. The result is written to the text "Smart ID Suite Validation".
  1. Choose a type in "New Entry Type" and click "Add".
  2. Click the row of the entry you want to use in the list to select it.
  3. Select objects in the 3D Viewport and click "Apply to Selection".
Note
When you choose multiple rows with the checkboxes at the far left, operation buttons such as "Apply to Selection" and "Select by Entry" process the checked rows together. When nothing is checked, they process only the one selected row (the active row). The icon buttons below the list (delete, duplicate, move) always target only the one selected row. If you click a checkbox while holding Shift, you can select all the visible rows from the previously checked row to the current row at once.

5-3. Selected Entry

This is where you view and edit the contents of the entry selected in the list.

LocationBelow "ID / Channel Library". It is open from the start. When no entry is selected, "No entry is selected." appears.

ItemWhat it does
EnabledWhen turned off, the entry stays in the list but is skipped by apply, validate, and export.
LockedWhen turned on, the entry is protected from deletion and overwriting. Use it for IDs that must not change.
TypeChooses what this entry manages. The fields in the box below change depending on the type.
NameThe name used in the list and in exports.
ID NumberThe number used for pass indexes (numbers that tell objects apart in a render) and for sorting.
Display ColorThe color used for ID materials, the viewport color of objects, the box and label colors of the Visual Overlay, and for telling entries apart in the list.
Map Channel / UV Map / Channel NameFor a "Map Channel" entry, all three appear; for a "UV Channel" entry, "UV Map" and "Channel Name" appear. They set, for example, the name of the UV map to create or activate. For a "UV Channel" entry, "Channel Name" is used when "UV Map" is empty; for a "Map Channel" entry, "UV Map" is used when "Channel Name" is empty.
Color Attribute / Attribute DomainAppears for "Color Attribute" entries. Sets the name of the color attribute (color values stored on the mesh) and where it is stored. A color attribute is created on "Point" or "Corner"; if you choose anything else, it becomes "Corner".
Attribute Name / Attribute Type / Attribute DomainAppears for "Geometry Attribute" entries. Sets the name of the attribute (values stored on the mesh), the kind of value ("Floating Point", "Integer", "Boolean", "Vector", "Floating Point Color"), and where it is stored ("Point", "Edge", "Face", "Corner").
Group NameAppears for "Selection Set" and "Weight Group" entries. The name of the collection or vertex group to create. "Channel Name" also appears below, and is used when "Group Name" is empty.
UDIM TileAppears for "UDIM Tile" entries. Records a tile number such as 1001. "Channel Name" also appears below.
Channel Name (Render AOV, Cryptomatte Tag, Custom ID)The name field that appears for these entries.
Export Tag / NotesA short name used at the export destination, and a free-form note. They appear for every type.
Scene Matches / Selection MatchesThe number of objects, materials, and channels that match this entry. When there are target objects in the "Library Match Scope", the "Selection Matches" count also appears. Right after you change the selection, "Selection Matches" is not shown until the counts are refreshed.

5-4. Assignment Settings

This section header decides where and how "Apply to Selection" assigns entries.

LocationBelow "Selected Entry". It is closed at first.

ItemWhat it does
Target ScopeChooses the assignment target from "Selected Objects", "Active Object", "Scene Objects", and "All Mesh Objects". It is "Selected Objects" at first.
Material TargetChooses the slots that Material IDs are written to. The options are "Active Material Slot", "All Material Slots", "Selected Faces", and "Create and Assign ID Material".
Write Blender Pass IndexWhen turned on, writes the numbers of Object IDs and Material IDs to Blender's pass indexes. It is turned on at first.
Write Custom PropertiesWhen turned on, writes SmartID Suite records to objects and materials. This lets you find IDs even if the pass index changes. It is turned on at first.

Create Selection CollectionPuts the objects in the "Target Scope" into the collection named by the entry's "Group Name" (or "Channel Name" if empty). If the collection does not exist, it is created.

Assign ID Numbers to Objects

Assign Object IDs used in compositing to objects with the numbers you decide.

SmartID Suite

Give the selected material IDs the numbers 20 and 21

Use SmartID’s Renumber command to give checked library entries consecutive numbers. Set a start number and a step, then check the changed rows in the same list.

  1. 01Set up the starting list

    Use a practice library with three Material ID entries: Clay = 7, Glaze = 34 and Glass = 70. In ID / Channel Library, set Filter Type to Material ID.

    Tick the leftmost checkboxes for Clay and Glaze only. Leave Glass unticked. All three entries are enabled and unlocked. Automatic colors are off in the pictured example.

    The blue highlight identifies the current row. The checkboxes at the far left choose the rows to renumber. With no rows checked, the command targets all unlocked entries that match the filter type.

  2. 02Click Renumber

    Open Check / Import / Export. Set Renumber Start to 20 and Renumber Step to 1.

    Check that the two intended rows are ticked, then click Renumber once.

    A step of 1 increases the number by one for each row. The two entries in this example become 20 and 21.

  3. 03Read the three-digit numbers

    Look for 020 beside Clay and 021 beside Glaze. The unchecked Glass entry should still show 070.

    EntryBeforeAfter
    Clay007020
    Glaze034021
    Glass070070

    This operation changes the numbers of the library entries. In the captured example, the pass indices already assigned to the scene’s materials remain 7, 34 and 70.

  4. 04Restore the original 7 and 34

    The original numbers are not consecutive. Use the same Renumber command on one entry at a time to restore them.

    1. Tick only Clay at the far left. Set Renumber Start to 7 and click Renumber.
    2. Tick only Glaze. Set Renumber Start to 34 and click Renumber again. Leave Renumber Step at 1.
    3. Check that the list reads Clay 007, Glaze 034 and Glass 070.
    4. To restore the practice settings as well, tick Clay and Glaze and set Renumber Start back to 20. Do not click the button at this point.

    When using your own file, restore the original numbers you noted before the operation.

7. Troubleshooting

An entry I registered does not appear in the list.
When "Library Match Scope" is "Selected Objects" or "Active Object", only the entries contained in the selected items appear. Entries that have not been used anywhere yet, and selected or checked rows, always appear. After you change the selection, all rows appear until you click "Selection Changed: Refresh". Setting it to "Scene Objects" shows everything. Also check "Filter Type" and the search text. Conversely, Object ID rows that match the selected items stay in the list even if they do not match "Filter Type" or the search.
The count in the list shows as "-/1".
It means the counts have not been refreshed since the selection changed. Click "Selection Changed: Refresh" below the list to recount with the current selection and narrow down the rows.
Nothing changes when I click "Apply to Selection".
Disabled entries and locked entries are not assigned. Check "Enabled" and "Lock" in "Selected Entry". Also check whether there are objects in the "Target Scope" of "Assignment Settings" (for example, whether anything is selected).
The "Selected Object Inspector" list is empty.
"Selection Inspector Auto Refresh" is "Off" at first, so the list is not built automatically. Select objects and click "Refresh Selection Data".
Where can I see the "Validate" result?
It is written to the text "Smart ID Suite Validation". Open it in the Text Editor to view it. The number of entries and the number of warnings also appear in "Last Report".
I cannot delete an entry.
Locked entries are protected from deletion. Turn off "Lock" in "Selected Entry" and then delete it.
The overlay boxes appear on only some of the objects.
When "Overlay Source" is "Visible Entries", boxes are drawn to match the list. When "Library Match Scope" is "Selected Objects" or "Active Object", boxes appear only on the objects in that scope. To see the whole scene, set it to "Scene Objects".
Does the overlay appear in renders?
No. It is a display for checking that is drawn only in the 3D Viewport, and it does not change material or mesh data either.
I cannot import a JSON file.
When it cannot be imported, the reason appears in the "Last Report" row in Japanese. If the contents contain an error, the whole import is canceled.
"RESTART REQUIRED" appears in the panel.
The parts that SmartID Suite uses (classes and properties) were already registered as something else, so the features are stopped for safety. Restart Blender and then use it.

For problems common to every add-on, such as an add-on not appearing or the interface language not changing, see "Troubleshooting" in the SmartTools Overall Specification.

8. Glossary

Entry
One row of the list. It holds the definition of one ID or channel (type, name, number, color, and so on).
Pass Index
A number assigned to an object or material. It is used to tell items apart in compositing after rendering.
Material Slot
A slot in which an object holds a material. One object can have several.
UV Map
Coordinates that unfold a 3D shape flat so that a texture can be applied. One mesh can have several.
Map Channel
The numbered name for a UV used in 3ds Max. This add-on records it as a number and matches it with the name of a UV map.
Attribute
A value stored on the vertices, faces, and so on of a mesh. An attribute that holds a color is called a color attribute.
Domain
Where the values of an attribute are stored. The options are vertex (Point), Edge, Face, and Corner (the corner of a face).
Vertex Group
A named set of mesh vertices grouped together.
Collection
Something like a folder that groups objects. A selection set is created as a collection.
UDIM
A method of splitting a texture into multiple tiles numbered 1001, 1002, and so on.
AOV
An extra output for images in a render, separate from the normal image.
Cryptomatte
A mechanism for extracting a mask for each item after rendering.
Custom Property
A named value that you can freely attach to objects and materials.
Active
The one you selected last among the selected items.

Limitations and Notes

  • The Visual Overlay is drawn only in the 3D Viewport. It does not appear in renders.
  • The value type and domain of an existing attribute can only be viewed in the inspector. They cannot be changed (because Blender fixes them when the attribute is created).
  • Color attributes can be created only on "Point" or "Corner".
  • Locked entries are not targets of deletion, renumbering, and similar operations.
  • When importing JSON, if the contents contain an error, the whole import is canceled.
  • CSV is export only. There is no import from CSV.
  • When there are many rows, the inspector list shows only some of them. The original data of the rows that cannot be displayed does not change.
  • For Custom ID and Cryptomatte Tag, an object is identified only by the last one assigned. If you assign a Cryptomatte Tag to the same item after a Custom ID, the Custom ID row no longer matches.
  • When objects exist only directly under the scene, the Scene Collection row (Set_Scene Collection) stays in the list with a count of 0/0.
