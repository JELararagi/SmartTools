Installing SmartTools

Blender 5.1.0 or later / Installing an individual add-on

Check the filename first. Install an individual add-on ZIP directly. Extract a download bundle once to get the add-on and its help files. Installation works offline.

Requirements

  • Blender 5.1.0 or later (tested with Blender 5.1.2).
  • The ZIP of the add-on you want to install.

Download the ZIP

Choose a product from the download list on the home page or from Releases on GitHub.

Which ZIP should I select?

The filename ends in -download.zip
Extract the outer bundle once. For a set, open each product folder inside. In Blender, choose Install from Disk and select the ZIP inside that carries the product name and version.
You already have the individual product ZIP
Select this ZIP directly in Blender, keeping it zipped. This applies when you download the individual add-on from the GitHub download list.
See which file to open in a Smart Composite Suite 1.0.0 bundle 
SmartComposite_1.0.0-download.zip  ← extract once
├─ SmartComposite_1.0.0.zip        ← select in Blender
├─ help/en/index.html              ← read in your browser
└─ examples/Platform_Sign_Start.blend  ← open for the exercise

The included guide works offline. Example filenames and availability vary by product.

If Blender reports a missing manifest, look inside the ZIP you selected. An installable extension has blender_manifest.toml at the top level. If you see another product ZIP inside, extract the bundle and choose the inner ZIP.

Install in Blender

A. Drag and Drop

  1. Start Blender.
  2. Drag and drop the downloaded ZIP onto the Blender window.
  3. When the confirmation dialog appears, make sure Enable on Install is checked, then continue.

B. From the Menu

  1. Open Edit → Preferences... from the menu at the top.
  2. Select Get Extensions in the list on the left.
  3. Open the ∨ (down arrow) menu at the top right and choose Install from Disk....
  4. In the file browser, select one downloaded ZIP and click Install from Disk.
  5. Open Add-ons in the list on the left and make sure the add-on you installed is checked (enabled).

If another version of the same add-on is already installed, remove it before installing (Overall Specification, Chapter 8). If an old and a new version are installed at the same time, panels may appear twice or registration may fail.

Install from a Remote Repository (Receive Updates)

If you add this site to Blender as a remote repository, all 23 add-ons appear in the Get Extensions list, and you can install and update them from within Blender.

  1. Open Edit → Preferences... → Get Extensions.
  2. Open Repositories at the top right and choose + → Add Remote Repository.
  3. Enter https://jelararagi.github.io/SmartTools/downloads/index.json in URL. To check for updates automatically, check Check for Updates on Startup.
  4. If online access is turned off, check Allow Online Access in System → Network.
  5. Install the add-ons from the list.

Verify the Files (Optional)

You can check that a downloaded ZIP is not corrupted with its SHA-256 value. If the value you get matches the one in SHA256SUMS.txt, the file is fine (upper and lower case do not matter).

  • Windows (PowerShell): Get-FileHash .\Smart_UV_Suite_1.0.0.zip -Algorithm SHA256
  • macOS / Linux: shasum -a 256 Smart_UV_Suite_1.0.0.zip

Troubleshooting

  • See Overall Specification, Chapter 9 “Troubleshooting”.
  • Disabling and reinstalling: Overall Specification, Chapter 8
  • Uninstalling: in the Add-ons list, open the ∨ on the right of the add-on's row and choose Uninstall.

Check the distribution terms

Open the add-on ZIP you received and check the license field in blender_manifest.toml and the enclosed license notices. Different downloads of the same product can carry different notices.
