この製品について

UV（ユーブイ）は、立体の表面を平らな紙のように開いて、画像を貼る位置を決めるための座標です。SmartUV Suite は、この UV を作る・整える・並べる作業に使うボタンと設定を、サイドバーの「Smart UV」タブにまとめています。パネルの中は「常時機能切り替え」「基本設定」「UV展開」「UV整列」「パッキング」「ベイク」「操作」「管理」「キーマップ情報」の順に並んでいます。どの見出しも、三角の印か見出しの文字を押すと開いたり閉じたりできます。見出しの右にある「？」を押すと、その場所の説明が出ます。ほとんどの操作は、UV エディターで選んでいる UV だけに働きます。

1. このアドオンでできること

シームの位置を自動で決める「自動シーム」から、展開・記号のボタンでの整列・18 種類のプリセットで並べる自動パッキング・ベイクまでを、サイドバーの「Smart UV」タブ 1 つにまとめたアドオンです。

  • 選んだ部分の UV を、方式を選んで 1 つのボタン（「展開実行」）で展開する
  • シーム（UV を切り開く線）を手で付け外ししたり、自動で付けたり、クリース値から付けたりする
  • UV の頂点やアイランド（ひと続きの UV のかたまり）を、上下左右・中央にそろえる、均等に並べる、反転・回転する
  • UV を直線にする、円にする、リラックス（伸びをならす）する、縫い合わせる（スティッチ）
  • プリセットを選んで、UV を画像の中にすき間なく並べる（自動パッキング）
  • ベイク用の UV マップと画像を作り、マテリアルの色を画像に焼き付ける
  • チェッカー（白黒の格子）画像を作って、UV の伸びや大きさの差を目で確かめる
  • テクセル密度（UV の細かさ）を測る・そろえる
  • 1 つのオブジェクトに複数ある UV マップ（UV の座標の組）を追加・名前変更・並べ替えする
  • 重なり・裏返り・面積ゼロなど、UV の問題を数える・選ぶ・直す
  • UV エディターでのクリック選択からのドラッグ移動などを補助する機能を切り替える
こんな時に
  • モデルの UV を初めて作るとき：シームを付けて「展開実行」で開く
  • 展開した UV の向きや並びを整えるとき：「UV整列」の「方向整列」や「ライン・フロー」を使う
  • テクスチャ用に UV を 1 枚の画像へまとめるとき：「パッキング」の「自動パック実行」を使う
  • UV が伸びていないか確かめるとき：「プレビュー/チェッカー」でチェッカーを作る
  • マテリアルの色を 1 枚の画像にまとめるとき：「ベイク」＞「ベイク準備」のボタンを順に押す
  • 複数のオブジェクトで使う UV マップの番号と名前をそろえるとき：「マップチャンネル」を使う

2-1. 自動シームいちばんの売り

UV を開くには、どこで切るか（シーム）を決める必要があり、慣れないといちばん迷う所です。「自動シーム」は、形の折れ・開いた境界・マテリアルの変わり目・シャープの印などを点数にして辺を選び、シームを付けます。折れの無い筒や球、穴の貫通したドーナツ形にも、平らに開くのに要る最小限の切れ目を足すので、続けて「展開実行」を押すだけで開けます。「ハードサーフェス」「オーガニック」「筒状/パイプ」など 8 種類の用途から選ぶだけで、細かい値がまとめて切り替わります。

使い方
  1. メッシュを選び、編集モードで全部を選ぶ。
  2. 「UV展開」＞「シーム/ピン」＞「自動シーム詳細」を開き、④「自動シーム設定」で形に合う用途を選ぶ（硬い折れ目の多い物は「ハードサーフェス」、大きな曲面を切りたくない物は「オーガニック」、筒は「筒状/パイプ」）。
  3. ⑩「自動シーム」を押し、赤い線で入ったシームを確かめる。
  4. 「スマートUV展開」の「展開実行」を押す。
ここが新しい
  • 折れ角だけを見る ⑪「角度シーム」では、筒・球・ドーナツ形には線が入らない。⑩「自動シーム」は、それらにも開くのに要る切れ目を足す。
  • 線が多すぎる時は ⑤「採用スコア」を上げ、少なすぎる時は下げる。
  • 続けて「パッキング」の「自動パック実行」を押せば、シームを考えずに、展開から並べるまでを通せる。

くわしい設定：5-10. シーム/ピン、5-8. スマートUV展開

2-2. 自動パッキング（18 種類のプリセット）図で見る

アイランドを画像の中にすき間なく並べる「パッキング」を、目的に合わせた 18 種類のプリセットから選んで、1 回で行います。プリセットを選ぶと、回転・余白・UDIM・グループなどの値がまとめて切り替わるので、細かい設定を覚えなくても、「高密度パック」「マテリアル別パック」「同一島スタック+パック」「UDIMタイルパック」「ライトマップパック」のように名前で選べます。下の 2 組は、立方体の UV を「パック」と「同一島スタック+パック」で並べた前と後です。

使い方
  1. UV エディターで、並べたいアイランドの面をまるごと選ぶ。
  2. 「パッキング」＞「自動パッキング」の ①「プリセット」で並べ方を選ぶ。
  3. ②「自動パック実行」を押す。
知っておくこと
  • 実行の時は、③〜⑤ に今出ている値が使われる。プリセットを選んでから値を少し変えて実行してもよい。
  • 同じ形の島を重ねて画像を節約するなら「同一島スタック+パック」、画像を何枚にも分けるなら「UDIMタイルパック」のように、目的の名前のプリセットを選ぶ。
  • 並ぶのは面をまるごと選んでいるアイランドだけ。並べたくない島は選ばずにおけば動かない。

くわしい設定：5-19. パッキング

2-3. 方向整列（記号のボタン）図で見る

選んだ UV やアイランドを、端・中央へそろえる、均等に並べる、反転・回転するボタンを 1 か所にまとめています。ボタンには文字の代わりに、動く向きを表す矢印などの記号が出て、押した矢印の向きがそのまま結果の向きになります。記号だけでは分かりにくいので、下の図でどのボタンが何をするかを示します。

使い方
  1. UV エディターで、そろえたい UV を選ぶ。
  2. 「UV整列」＞「方向整列」の ①「対象」で「頂点」か「アイランド」を選ぶ。
  3. ②〜⑧ のうち、動かしたい向きのボタンを押す。
知っておくこと
  • 「アイランド」でそろえる時、そろえる向きと直角の位置はそのままなので、高さの近い島どうしは重なることがある。
  • ④⑥ の「G」の付いたボタンは、①「対象」が「頂点」の時だけ出る。

くわしい設定：5-13. 方向整列

5-1. 常時機能切り替え

パネルのいちばん上にある、続けて働く機能のオン・オフをまとめた場所です。1 回押して終わる操作はここにはありません。初めは閉じています。各行の右のボタンが「有効」か「無効」かで今の状態が分かり、押すと切り替わります。

場所「Smart UV」タブ ＞ いちばん上の「常時機能切り替え」（時計の印）

表示働き
「Nパネル状態保存」有効にすると、パネルの設定を変えるたびに Blender の設定フォルダの中のファイルへ保存し、Blender を開き直した後も元に戻します。無効の間は保存しません。始めは有効です。
「ライブ展開」Blender のライブ展開（ピン留めした UV を、シームの編集中に自動で更新する機能）を有効のままにします。
「UV同期選択」3D ビューのメッシュの選択と、UV エディターの選択を同じにします。UV だけを別に選びたい時は無効にします。
「Smart自動UV同期」SmartUV Suite の自動 UV 同期の希望の状態を覚えさせます。必要な時だけ有効にします。
「Smart展開リアルタイム更新」展開の設定を変えた時に、直前の展開を自動でやり直せるようにします。編集を軽くしたい時は無効にします。
「トランスフォーム保護」古いファイルに残った SmartUV Suite の目印を、オブジェクトの位置・回転・大きさを保ったまま取り除く仕組みを入れます。古いファイルで必要な時だけ有効にします。
「Blender 5.1互換修復」起動設定などに古い値が残って Blender 5.1 で警告が出る時に、それを直す仕組みを入れます。警告が出る時だけ有効にします。

マップチャンネルは、1 つのオブジェクトが持つ UV マップ（UV の座標の組）の番号と名前のことです。選んでいるメッシュのオブジェクトを一覧にして、それぞれが展開にどの UV マップを使うかを表示し、一覧で選んだオブジェクトだけを編集します。

表示働き

「リスト選択オブジェクトの操作」とその下の名前ここから下が、一覧で選んだオブジェクトの設定です。すぐ下にそのオブジェクトの名前が出ます。

5-10. シーム/ピン

場所「Smart UV」タブ ＞ 「UV展開」 ＞ 「シーム/ピン」

表示働き
「シーム準拠/保存」「展開前シーム準拠」がオンだと、付けてあるシームを切れ目として展開します（始めはオンです）。展開してもシームは消えません。「シーン保存」「シーン読込」でシームをファイルの中に、「外部保存」「外部読込」で外の JSON ファイルに保存・読み込みします。名前は「シーン内保存名」、保存先は「外部JSON」で決めます。
「シームをマーク」「シームをクリア」編集モードで選んだ辺にシームを付けます／外します。
「クリース値シーム」「クリース値」に合う辺にシームを付けます。「許容差」でどこまで近ければ合うとするか、「適用方式」で今のシームに足す（「加算」）か、全部消してから作る（「クリア後に作成」）かを決め、「クリース値でシーム化」を押します。
「ピン」「ピン解除」「ピン反転」選んだ UV にピンを付ける／外す／付け外しを入れ替えます。
「自動シーム設定」（「自動シーム詳細」の中）用途に合わせて、下の値をまとめて切り替えます。「手動調整」は今の値のまま使います。「バランス」は角度・引張・境界を平均的に見ます。「ハードサーフェス」は硬い折れ目・シャープ・マテリアル境界で切ります。「オーガニック」は折れ角のしきい値を緩め、大きな連続面を切りにくくします。「筒状/パイプ」は筒を側面 1 枚にまとめやすくします。「低引張」は引張予測を強め、折れ角などの根拠がある辺を切りやすくして歪みを抑えます。「ループ維持」は長く続く辺の流れに沿わせます。「UV Atlas」は分割と伸びのつり合いを見ます。「Singleアイランド」は内部の切れ目をできるだけ減らします。
「採用スコア」「角度しきい値」「辺角度」「採用スコア」は辺をシームにする点数の下限で、低いほど線が増えます。「角度しきい値」はとなりの面との折れ角の基準で、「辺角度」はその折れ角をどれだけ重く見るかです。
「引張予測」「ループ維持」伸びやすそうな所や長く続く辺の流れを見て、折れ角などの根拠がある辺を後押しする強さです。これだけではシームになりません。
「筒状ループ」「筒状角度幅」「筒状軸」「筒状カット本数」筒の形に縦の切れ目を入れる時の強さ、筒と見なす角度の幅、筒の向き（「自動」「X」「Y」「Z」）、切れ目の本数です。
「境界」「マテリアル」「シャープ」開いた境界、マテリアルの変わり目、シャープの印が付いた辺を、どれだけ強くシームの候補にするかです。
「先にクリア」「開口境界」「先にクリア」をオンにすると、今のシームを消してから作り直します。「開口境界」をオンにすると、穴や開いた縁もシームの候補にします。
「自動シーム」「スマートシーム」上の設定で辺を調べて、シームを付けます。閉じた形・穴の貫通した形・筒には、平らに開くのに要る最小限の切れ目も足します。どちらのボタンも同じ判定です。

「制約展開」ピンの UV を動かさずに、選んでいる UV を展開し直します。動かしたくない UV に先に「ピン」を付けておきます。

「条件/問題選択」の「反転面」「ゼロ領域」「UDIM跨ぎ」UV が裏返った面、UV の面積がゼロの面、最初のタイルの外にある・タイルをまたぐ面を選択に足します。

5-14. ライン・フロー

選んだ UV の並びを、まっすぐや円などのきれいな形に整える場所です。

場所「Smart UV」タブ ＞ 「UV整列」 ＞ 「ライン・フロー」

表示働き
「辺を整列」UV の辺か頂点を線状に選んで押すと、その線を一直線にそろえます。面全体を選んでも一直線にはしません。
「ワールド軸整列」選んだ領域を形を変えずに回して、3D の軸の向きにそろえます。線状に選んだ時は、長い方向へまっすぐ寝かせます。
「直線化」「均等直線化」線状に選んだ UV を一直線にします。「直線化」は両端を結ぶ線へ寄せるだけで間隔はそのまま、「均等直線化」は間隔もそろえます。離れた行を選んだ時は、行ごとに別々に直します。
「矩形補正」選んだ領域ごとに四角く整えます。四角ポリゴンの格子は行と列がまっすぐにそろい、選んだ形のままです（L 字は L 字のまま）。それ以外の形は外周が四角形になります。面はつながったままで、周りの UV も一緒に動きます。
「円形化」選んだ頂点の輪を円に並べます。面を選ぶと外周を円にして内側を合わせます。閉じた輪でない線は円にしません。
「正規化」選んだ UV を囲む四角の位置と大きさを、枠に合わせて整えます。
「リラックス」と「リラックス反復」選んだ UV の内側をならして伸びを減らします。選んだ領域の外周は動きません。「リラックス反復」はならす回数です。
「フロー設定」と「フロー強度」選んだ頂点の並びを、なめらかな流れに整えます。「フロー強度」で効き方を決めます。

5-19. パッキング

パッキングは、UV のアイランドを画像の中にすき間なく並べることです。中の「自動パッキング」でプリセットを選んで「自動パック実行」を押します。対象は UV エディターで面をまるごと選んでいるアイランドだけで、選んでいない UV は動きません。

場所「Smart UV」タブ ＞ 「パッキング」 ＞ 「自動パッキング」

表示働き
「プリセット / 実行」の「プリセット」並べ方を選びます。選ぶと、下の設定の値がそのプリセットに合わせて切り替わります。実行の時は、下に出ている設定の値が使われます。「パック」「高密度パック」「方向維持パック」「密度優先パック」「3D面積基準パック」「類似島グループパック」「マテリアル別パック」「同一島スタック+パック」「UDIMタイルパック」「UDIM維持パック」「UDIM自動拡張パック」「高密度チャート分布パック」「ベイク安全チャートパック」「既存チャート再パック」「低歪み補正パック」「ライトマップパック」「ホットスポットセル配置」「トリム帯配置」があります。始めは「パック」です。
「自動パック実行」選んだプリセットと下の設定で、対象のアイランドを重ならないように枠の中へ並べ直します。
「基本パック設定」「重なり島を複合島にする」（重なったアイランドを 1 つとして並べる）「ピン固定」「回転を許可」「回転刻み」「スケールを許可」「形状方式」を決めます。「形状方式」はアイランドの形の見方で、「凹」（へこみも含めて正確に見る）「凸」（へこみを埋めた形で見る。正確さと速さの中間）「AABB」（外側を囲む四角で見る。速い）から選びます。始めは「凹」です。
「余白 / 探索」アイランドの間のすき間（「余白px」「標準余白」「余白方式」）と、並べ方を試す「Seed探索」「Seed」を決めます。
「タイル・UDIM・サイズ」初めは閉じています。並べる先のタイル（「配置タイル」「タイルU」「タイルV」）、UDIM（複数枚の画像のタイル）の「UDIM列数」「UDIM埋め順」、「パック幅」「パック高さ」を決めます。
「グループ / 密度」初めは閉じています。「グループ方式」「グループ配置」「面積許容差」「比率許容差」「同一島を重ねる」「チャート密度再正規化」を決めます。
「ベイク / ホットスポット」初めは閉じています。「ベイク安全余白」と、ホットスポット（格子のマスに区切った配置）の「列数」「行数」「縦横比を保持」「ソート規則」「埋め順」を決めます。

実例小さく散らばった UV を「自動パック実行」で敷き詰める（立方体で試した様子）

UV が画像の一部にしか乗っていないと、テクスチャの解像度が無駄になります。「自動パック実行」は、選んでいる島を並べ直して画像の中に大きく敷き詰めます。

  2. UV エディターで UV を全部選ぶ
  3. 「Smart UV」タブ ＞「パッキング」＞「自動パッキング」を開く
  4. 「自動パック実行」を押す

見どころ：小さく散らばっていた 6 つの島が、2 列 3 段にすき間なく大きく並び直りました（右側には少し余りが残ります）。同じ画像でも、面に乗る画素が増えて細かく描けます。

5-21. ベイク準備

ベイクに使う値を入れ、UV マップの用意から焼き付け、焼いた画像のマテリアル作りまでを順に行う場所です。

場所「Smart UV」タブ ＞ 「ベイク」 ＞ 「ベイク準備」

表示働き
「テクスチャサイズ」「ベイク余白」「目標密度」「余白方針」「テクスチャサイズ」はベイク画像の大きさ、「ベイク余白」はアイランドのまわりの余白（ピクセル）です。「目標密度」には「テクスチャから密度」が測った値が入ります。「余白方針」は「詳細展開」の余白の決め方です。
「ベイクUV準備」選んでいるオブジェクト全部に、今の UV を写した UV マップ「UV_Bake」を作って作業用にし、全部のアイランドを枠の中に並べます。元の UV マップはそのまま残ります。複数のオブジェクトを 1 枚に焼く時は、先にこれを押すと UV が重なりません。
「ベイク画像作成」「テクスチャサイズ」の大きさの画像「SmartUV_Bake」を作り、選んでいるオブジェクトのマテリアルに焼き先として設定します。マテリアルが無いオブジェクトには作ります。
「アトラスベイク」選んでいるオブジェクトのマテリアルの色を、作業用の UV マップで画像「SmartUV_Bake」に焼き付けます（Cycles を使います）。焼き先が無ければ先に作ります。色だけを焼きます。「マテリアル作成」の後にもう一度押すと、元のマテリアルの色から焼き直して、画像を新しくします（元のマテリアルの色を変えた時に使います）。
「マテリアル作成」焼いた画像を使うマテリアル「SmartUV_Baked」を作り、選んでいるオブジェクトの全部の面に当てます。画像を焼いた時の UV マップを使います。元のマテリアルはスロットに残り、面ごとの元の当たり方も覚えています。まだ焼いていない時と、選んでいるオブジェクトにその UV マップが無い時は、知らせを出して何もしません。

5-22. テクセル / マップ生成

テクセル密度は、3D の大きさに対して UV にどれだけ画像の細かさを割り当てているかです。これを測ったり、そろえたりします。

場所「Smart UV」タブ ＞ 「ベイク」 ＞ 「テクセル / マップ生成」

表示働き
「密度取得」「密度設定」「密度正規化」「密度取得」は選んでいる UV の今の密度を測って覚えます。「密度設定」は選んでいる UV 全体を同じ倍率で拡大・縮小して、覚えた密度に合わせます。「密度正規化」は選んでいる UV 全体を同じ倍率で拡大・縮小して、UV の広さと 3D の広さが同じ割合になるようにします。どれもアイランドどうしの大きさの比は変わらず、枠からはみ出すことがあります。比をそろえるには「標準補助 / 平面化」の「平均スケール」を使います。
「カバー率」「UV面積」「カバー率」は UV が枠をどれだけ使っているかを、「UV面積」は選んでいるアイランド（無ければ全部）の UV の面積と 3D の面積を、画面の下の知らせに出します。UV は変わりません。
「テクスチャから密度」UV エディターに出ている画像か、マテリアルの画像（無ければ「テクスチャサイズ」）の大きさで密度を測り、画面の下に出して「目標密度」に入れます。UV は変わりません。
「密度レポート」選んでいるオブジェクトのテクセル密度を計算して、画面の下の知らせに「テクセル密度: ○○ px/unit」の形で出します。UV は変わりません。

実例小さすぎる UV を「密度正規化」で 3D の広さに合わせる（立方体で試した様子）

UV が画像の一部にしか乗っていないと、模様のマスが大きく粗く写ります。「密度正規化」は、選んでいる UV 全体を同じ倍率で拡大・縮小して、UV の広さと 3D の広さが同じ割合になるようにします。

→
→
→
操作
  1. 立方体を選び、編集モードで全部の面を選ぶ
  2. UV エディターで UV を全部選ぶ
  3. 「Smart UV」タブ ＞「ベイク」＞「テクセル / マップ生成」を開く
  4. 「密度正規化」を押す

見どころ：大きくて粗かったマスが細かくなりました。UV エディターでは、島の並びと島どうしの大きさの比はそのままで、全体が同じ倍率で広がっています。物の大きさによっては枠からはみ出すので、その時は「自動パック実行」で並べ直します。

「セット保存」「セット読込」「セット更新」「セット保存」は選んでいる面に名前を付けてオブジェクトに保存します。「セット読込」は一覧から選んだセットの面を選び直します。「セット更新」は一覧から選んだセットを今の選択で置き換えます。

UV の問題を数える・選ぶ・直す場所です。「状況確認 / 修復」「仕上げ選択チェック」「データ整理」に分かれています。

場所「Smart UV」タブ ＞ 「管理」 ＞ 「整理」

表示働き

6. よく使う手順

立方体の UV を展開して並べる

シームを付けて展開し、画像の中にきれいに並べる

  1. 立方体を選び、Tab キーで編集モードに入ります。
  2. 辺選択（2 キー）にして、切り開きたい辺を選びます。
  3. 「UV展開」＞「シーム/ピン」の「シームをマーク」を押します。
  4. A キーで全部を選び、UV エディターでも UV を全部選びます。
  5. 「スマートUV展開」の「方式」で「アングルベースで展開」を選び、「展開実行」を押します。
  6. 「パッキング」＞「自動パッキング」の「プリセット」で「パック」を選び、「自動パック実行」を押します。

結果：UV がシームで切り開かれ、画像の範囲の中にすき間をあけて並びます。

シームを考えずに開いて並べる

「自動シーム」に切れ目を任せて、展開からパックまで通す

  1. オブジェクトを選び、Tab キーで編集モードに入り、A キーで全部を選びます。
  2. 「UV展開」＞「シーム/ピン」＞「自動シーム詳細」の「自動シーム」を押します。
  3. 「スマートUV展開」の「展開実行」を押します。
  4. 「パッキング」＞「自動パッキング」の「自動パック実行」を押します。

結果：形の折れに沿ったシームで切り開かれ、アイランドが重ならずに枠の中へ並びます。

チェッカーで伸びを確かめる

UV の伸びや大きさの差を目で見る

  1. 確かめたいオブジェクトを選びます。
  2. 「基本設定」＞「プレビュー/チェッカー」で、「画像解像度 横」「画像解像度 縦」と「チェックサイズ 横」「チェックサイズ 縦」を決めます。
  3. 「チェッカー作成」を押します。
  4. 「マテリアルに反映」を押します。3D ビューの表示を「マテリアルプレビュー」にすると、格子が貼られた見た目になります（このボタンは 3D ビューの表示の切り替えまではしません）。
  5. 確かめ終わったら「マテリアルを元に戻す」を押し、要らなければ「チェッカー削除」を押します。

結果：格子のマスがつぶれたり大きさが違ったりする所で、伸びや密度の差が分かります。

アイランドを左端にそろえる

選んだアイランドの左の端をそろえる

  1. UV エディターでそろえたいアイランドを選びます。
  2. 「UV整列」＞「方向整列」の「対象」で「アイランド」を押します。
  3. 「←」のボタンを押します。

結果：選んだアイランドが、形を保ったまま左の端でそろいます。

複数のオブジェクトの UV マップの番号と名前をそろえる

複数のオブジェクトで展開に使う UV マップをそろえる

  1. そろえたいメッシュのオブジェクトを全部選びます。
  2. 「基本設定」＞「マップチャンネル」の一覧で、基準にするオブジェクトの行を押します。
  3. 「展開使用マップチャンネル」で使う UV マップを選びます。
  4. そろえたいオブジェクトの行の左のチェックを入れます。
  5. 「チェック対象を統一」を押します。

結果：チェックしたオブジェクトの展開用 UV マップの番号と名前が、基準のオブジェクトと同じになります。

マテリアルの色を 1 枚の画像に焼き付ける

複数のオブジェクトの色を 1 枚にまとめて、そのマテリアルに切り替える

  1. まとめたいオブジェクトを全部選びます。
  2. 「ベイク」＞「ベイク準備」の「テクスチャサイズ」と「ベイク余白」を決めます。
  3. 「ベイクUV準備」を押します。「UV_Bake」という UV マップができ、アイランドが枠の中に並びます。
  4. 「アトラスベイク」を押します。画像「SmartUV_Bake」に色が焼き付きます。
  5. 「マテリアル作成」を押します。

結果：焼いた画像を使うマテリアル「SmartUV_Baked」に切り替わり、見た目は元の色のままです。画像は .blend の中に保存されます。元のマテリアルの色を変えた時は「アトラスベイク」をもう一度押すと、画像が新しい色に変わります。

「チャンネル名変更」は UV マップが無い時に押せません。「上へ移動」「下へ移動」は、UV マップが 1 つしか無い時や、もういちばん上・下にある時に押せません。UV マップが無ければ、まず「追加」で作ってください。
パネルの開け閉めや設定は、次に開いた時も残りますか。
「常時機能切り替え」の「Nパネル状態保存」が「有効」なら、変更のたびに保存され、Blender を開き直した後も戻ります。「無効」にすると保存しません。
「自動パック実行」で一部の UV が動きません。
自動パッキングは、UV エディターで面をまるごと選んでいるアイランドだけを並べます。動かしたい UV が全部選ばれているか確かめてください。
プリセットを変えたら、下の設定の値も変わりました。
正しい動きです。プリセットを選ぶと、下の設定がそのプリセットの値に切り替わります。実行の時は、下に出ている値が使われるので、変えたい所があれば実行の前に直してください。
「密度正規化」を押しても、面ごとの模様の大きさの違いがそろいません。
「密度正規化」は選んでいる UV 全体を同じ倍率で拡大・縮小します。アイランドどうしの大きさの比をそろえるには、「UV展開」＞「標準補助 / 平面化」の「平均スケール」を使ってください。
「自動シーム」は、角の無い球や筒にも線を入れますか。
はい。折れ角の根拠が無い形でも、閉じた形・穴の貫通した形・筒には、平らに開くのに要る最小限の切れ目を足します。
「ベイクUV準備」を押したら、UV の並びが変わりました。
新しい UV マップ「UV_Bake」を作って、そこで全部のアイランドを枠の中に並べ直したためです。元の UV マップはそのまま残っています。「マップチャンネル」で作業用の UV マップを元に戻せます。
「検証」を押しても UV が変わりません。
「検証」は問題の数を数えて画面の下に出すだけです。問題の面を選ぶ時は「問題を選択」を、直す時は「問題修復」を押してください。
「面積で選択」「密度で選択」を押すと、基準を選ぶよう知らせが出ます。
基準にするアイランドを先に 1 つ選んでから押してください。
「マテリアル作成」の後で元の色を変えました。焼き直せますか？
「アトラスベイク」をもう一度押してください。元のマテリアルの色から焼き直して、画像を新しくします。面には「SmartUV_Baked」が当たったままです。元のマテリアルのスロットを消してしまった面は焼き直せないので、知らせが出て止まります。
「マテリアル作成」を押すと「先に「アトラスベイク」を押してください」と出ます。
画像にまだ色を焼いていないためです。「ベイク画像作成」は空の画像を作るだけなので、「アトラスベイク」を押してから「マテリアル作成」を押してください。

アドオンが出ない・日本語にならない、など全部のアドオンに共通のことは、全体仕様書の「困った時」を見てください。

8. 用語集

UV（ユーブイ）
立体の表面を平らに開いて、画像のどこを貼るかを決める座標です。
UV マップ／マップチャンネル
1 つのオブジェクトが持つ UV の座標の組です。1 つのオブジェクトが複数持てます。
展開
立体の表面を切り開いて UV を作ることです。
シーム
展開の時に切り開く線として印を付けた辺です。
ピン
展開の時に動かさないように印を付けた UV の点です。
アイランド（島）
UV の中で、ひと続きにつながったかたまりです。
パッキング（パック）
UV のアイランドを、画像の中にすき間なく並べることです。
スティッチ
切れている UV の辺やアイランドを縫い合わせることです。
テクセル密度
3D の大きさに対して、UV にどれだけ画像の細かさを割り当てているかです。
UDIM（ユーディム）
UV の範囲を複数枚の画像のタイルに分けて使うしくみです。
チェッカー
白黒などの格子の画像です。貼ると UV の伸びや大きさの差が見えます。
ベイク
色や陰影などを画像に焼き付けることです。
キーマップ
キーやマウスの操作と機能の割り当ての一覧です。プリファレンスで見られます。
ギズモ
画面の上に出る、移動・回転・拡大縮小用の取っ手です。

できないこと・注意

  • 展開・整列・パックなどの UV の操作は、選んでいる UV だけに働きます（「UV同期選択」がオフで UV を何も選んでいない時の「展開実行」は、UV エディターに出ている面全部に働きます）。
  • 「自動パック実行」は、UV エディターで面をまるごと選んでいるアイランドだけを並べ、選んでいない UV は変えません。
  • 「ホバー頂点へ2Dカーソル」は、プリファレンスのキーマップに自分で登録しないと使えません。
  • 方向整列のグループごとのボタン（「G—」など）は、「対象」が「頂点」の時だけ出ます。
  • 「グリッド分割」は、「グリッド基準」が「ダイナミック」と「ピクセル」の時は出ません。
  • 「UVエディター操作の管理」の設定は UV エディターだけに働きます。
  • 「密度設定」「密度正規化」は選んでいる UV 全体を同じ倍率で拡大・縮小するので、アイランドどうしの大きさの比は変わりません。
  • 「UVミラー」「対称スナップ」「3Dミラー選択」は、オブジェクトの X 軸で左右対称なメッシュの面だけに働きます。
  • 「アトラスベイク」は Cycles でマテリアルの色だけを焼きます。陰影や法線を焼く時は Blender の「レンダー」のプロパティのベイクを使います。
  • 「問題修復」は面積ゼロの面を直しません。枠の外の UV も動かしません（UDIM で使っている場合があるためです）。
  • 「シーム読み込み」「配置読み込み」「選択読み込み」は、書き出した時と同じ面のつくりのメッシュにだけ使えます。
  • 「スマートスタック」は回して重なる物だけを同じ形と見ます。左右に裏返した形は別の形として扱います。
  • 複数のオブジェクトをまとめて「アトラスベイク」する時は、作業用の UV マップの名前をそろえてください。「ベイクUV準備」を押すと「UV_Bake」にそろいます。
