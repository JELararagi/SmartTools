SmartTools の入れ方

Blender 5.1.0 以上 ／ ZIP のまま入れます

ダウンロードした ZIP を、展開（解凍）せずにそのまま Blender に入れます。インターネットにつながっていなくても入れられます。

目次

  1. 必要なもの
  2. ZIP をダウンロードする
  3. Blender に入れる
  4. リモートリポジトリで入れる（更新を受け取る）
  5. ファイルを確かめる（任意）
  6. 入れた後に
  7. 困った時

必要なもの

  • Blender 5.1.0 以上（Blender 5.1.2 で動作を確かめています）。
  • 入れたいアドオンの ZIP。

ZIP をダウンロードする

トップページのダウンロード一覧、または GitHub の Releases から入手します。ZIP は展開しないでください。ブラウザーが自動で展開してしまった時は、もう一度 ZIP のままダウンロードしてください。

Blender に入れる

A. ドラッグ＆ドロップで入れる

  1. Blender を起動します。
  2. ダウンロードした ZIP を、Blender の画面にドラッグ＆ドロップします。
  3. 確認の画面が出たら、「インストール後有効化」にチェックが入っていることを確かめて進めます。

B. メニューから入れる

  1. 上のメニューの 「編集」→「プリファレンス...」 を開きます（英語の画面なら Edit → Preferences...）。
  2. 左の一覧から 「エクステンションを入手」（Get Extensions）を選びます。
  3. 右上の ∨（下向きの矢印） のメニューを開き、「ディスクからインストール...」（Install from Disk...）を選びます。
  4. ファイルを選ぶ画面で、ダウンロードした ZIP を 1 つ選び、「ディスクからインストール」を押します。
  5. 左の一覧の 「アドオン」 を開き、入れたアドオンにチェックが入っている（有効になっている）ことを確かめます。

同じアドオンの別の版がすでに入っている時は、先にそれを削除してから入れてください（全体仕様書 8 章）。古い版と新しい版が同時に入っていると、パネルが二重に出たり、登録に失敗したりします。

リモートリポジトリで入れる（更新を受け取る）

このサイトを Blender の「リモートリポジトリ」として登録すると、23 個のアドオンすべてが「エクステンションを入手」の一覧に出て、Blender の中から入れたり更新したりできます。

  1. 「編集」→「プリファレンス...」→「エクステンションを入手」 を開きます。
  2. 右上の 「リポジトリ」 を開き、「＋」→「リモートリポジトリを追加」 を選びます。
  3. URL に https://jelararagi.github.io/SmartTools/downloads/index.json を入れます。更新を自動で確かめたい時は 「起動時に更新チェック」 にチェックを入れます。
  4. インターネットへの接続が切れている時は、「システム」→「ネットワーク」 の 「オンラインアクセスを許可」 にチェックを入れます。
  5. 一覧に出たアドオンを、そこからインストールします。

ファイルを確かめる（任意）

ダウンロードした ZIP が壊れていないかは、SHA-256 の値で確かめられます。出た値が SHA256SUMS.txt の値と同じなら問題ありません（大文字・小文字の違いは気にしなくてかまいません）。

  • Windows（PowerShell）：Get-FileHash .\SmartUVSuite_1.0.0.zip -Algorithm SHA256
  • macOS・Linux：shasum -a 256 SmartUVSuite_1.0.0.zip

入れた後に

  • 画面を日本語にする：全体仕様書 4 章
  • N パネルと「？」ヘルプの使い方：全体仕様書 5 章
  • SmartTools 全体を管理する（Smart Tools Manager）：全体仕様書 6 章・Smart Tools Manager の解説書

Blender のエクステンションは、ファイル・ネットワーク・カメラなどを使う時、その「権限」を申告します。インストールの時に Blender が表示します。ネットワークとカメラを申告しているのは SmartShapekey Suite だけです（manifest の記載：ネットワーク：Download Face Tracker packages only when explicitly requested／カメラ：Read webcam video only while Face Tracker is explicitly running）。
